## 4. 每次自动核查的固定输出

即使没有触发，也输出一条简报：运行时间、七只证券最新可得价格及价格日期、相对基准变化、是否越过精确触发器、是否发现新的官方财报日／公告、目标仓位是否变化。

发现触发时，输出以下更新日志：

| 字段 | 内容 |
|---|---|
| detected_at | Australia/Melbourne时间 |
| company／security | 公司与证券 |
| source | 官方IR／监管公告／交易所／价格源链接 |
| previous_value | 旧价格、旧财报日或旧财务指标 |
| current_value | 新值 |
| trigger | 8%过期线／估值边界／正式财报日／业绩材料／治理事件 |
| fundamental_status | intact／weakened／broken／insufficient |
| decision_pr | 用新价格和仍有效盈利计算；财报后必须用新盈利重算 |
| target_weight | 单一百分比，不输出区间 |
| action | 保持／暂停新增／启动完整流水线复核／退出评估 |
| next_check | 具体日期、时间和时区 |

每条公告按URL、公告编号或申报accession去重。不得把媒体转载早于官方来源当作正式财报。自动任务只研究和通知，不创建订单、不执行交易。

## 5. 通知与运行边界

- 自动任务的结果回到当前任务及Scheduled收件箱；手机推送依赖ChatGPT手机端和账户的通知权限。
- 需要本地skill和本文件时，电脑必须开机、ChatGPT桌面应用保持运行、项目路径仍可访问。
- 普通定时轮询不能保证秒级发现。没有来自投资者关系网站或监管系统的原生事件触发时，以最近一次轮询时间作为发现上限。
- 若自动任务连续三次无法取得同一证券的可靠价格或官方页面，标为`monitoring_degraded`并通知，不用旧价格假装当日数据。
