# 公司查询固定格式

用户以公司名或证券代码调用本 skill 时，默认交付下列“表格决策卡”。图片、旧报告或附件只可作为版式参考；其中的数据、阈值和动作不自动成为本公司的事实或规则。

## `quick_valuation`展示例外

本节优先于下方完整格式。用户只说“跑一下”、只给公司名／代码，或要求“快算／只算估值／估值和退出”时，默认答复严格限于两个可见部分：**核心决策卡**和直接复用估值 skill 的**估值价格带**。截图、旧报告或附件中的数字、日期和动作只作版式参考，不写入通用规则。

### 核心决策卡固定模板

| 项目 | 当前结果 | 判断 |
|---|---:|---|
| 收盘价 | `{价格} {交易币种}` | `{YYYY-MM-DD}` |
| 归母 TTM EPS | `{数值／insufficient} {每股单位}` | `{同口径来源或基本面截止日}` |
| 归母 PE_TTM | `{倍数／insufficient}` | `{决策口径／限制}` |
| 归母 ROE_TTM | `{百分比／insufficient}` | `{五点平均权益或实际替代口径}` |
| 归母 ROA_TTM | `{百分比／insufficient}` | `{五点平均资产或实际替代口径}` |
| TTM扣非净利润同比 | `{百分比／数据不足，无法判断／基期异常，无法使用正常同比判断}` | `{估值 skill 的四季扣非利润交接及来源}` |
| 重大业绩下滑保护 | `{未触发／已触发／数据不足，无法判断／基期异常，无法使用正常同比判断}` | `{触发时写估值切换至悲观预测；其余简写原因}` |
| 决策 PR | `{唯一决策PR／insufficient}` | `{PR简式计算及相对价格线的判断}` |
| 修正系数 | `{市场系数c、股东回报系数N；缺失则insufficient}` | `{最新股息率口径、系数简算和适用状态}` |
| PB | `{倍数／insufficient}` | `{8PB 禁入闸门状态}` |
| 当前动作 | `{估值层动作}` | `{基本面确认状态；不含机械买卖指令}` |
| 仓位建议 | `不输出` | `快速模式跳过质量评分、同业和组合约束` |

固定规则：

- 标题固定为“核心决策卡”，列名固定为“项目／当前结果／判断”；以上十二行的名称和顺序不得增删、改名或重排。字段缺失时保留该行并填`insufficient`，重大业绩下滑保护缺数据时使用估值 skill 的状态文本。
- 表前不得另加状态栏、结论或汇总表。价格日期、基本面截止日、口径、来源链接、限制和失效条件全部就近写入对应“判断”单元格，不得为此新增行或第三个展示部分。
- “归母”指未扣非的GAAP／法定归母口径；按估值 skill 的正式口径计算EPS、PE、ROE、ROA与决策PR。扣非利润只用于估值 skill 定义的重大业绩下滑保护，不替换这四行数值或正式价格带的利润口径。缺少法定归母输入时填`insufficient`，不得拿扣非顶替。
- `执行PR＝决策PR`，它是唯一动作PR；`核验PR`只作内部验证，不产生动作许可，也不得新增一行。归一化估值位置如需展示，只能并入“决策 PR”的判断单元格。
- “判断”单元格用简短文字配关键数字说明计算过程。“决策 PR”行简写股息率选中的ROE档位、保护是否覆盖、PR计算和估值位置；独立的“修正系数”行写最新同价格日的股息率口径、市场系数、股东回报修正系数，逐项列数值、简式算式及生效或未触发原因。已公告但尚未除息的特别分红与已支付分红须标明日期和口径；股息率与可持续股利支付率分别按估值 skill 的规则判断，不得用只含常规年度派息的收益率冒充最新含特别分红收益率。公式和阈值只引用估值 skill，不在本模板重定义。
- “当前动作”只表达估值层状态及基本面确认状态，不构成交易或机械买卖指令。“仓位建议”在快速模式固定为`不输出`。

### 估值价格带

直接复用估值 skill 的买入与退出六档，只显示目标PR、目标价、相对现价变动和用途／状态，不在本文件复制公式、阈值或完整表样。

三年预测、纯现金覆盖、杜邦、压力情景、历史峰值样本、复核触发器、仓位、同业、质量评分和独立来源表只在内部计算；用户明确要求展开时才显示。不得把“内部需要计算”误写成“默认需要展示”。

## 总体原则

以下格式只适用于`full`模式，不得混入上述快速模式固定模板。

- 第一屏必须看见：当前动作、执行PR、首仓价格、本次新增仓位。
- `执行PR＝决策PR`，唯一负责建仓价格带、仓位档、当前动作，以及与个股历史`S／H／M／E`的比较；`核验PR＝当前TTM PR`，只核验财报估值和杜邦，不产生动作许可。周期股执行PR用`100 × 同期PB ÷ 执行ROE²`，非周期股用`PE_TTM ÷ 执行ROE`；执行ROE直接消费估值 skill 的股息率选档、重大业绩下滑保护与正式归一ROE交接，并沿用各类型的风险锚取低规则。
- 关键结果优先用表格；单表通常不超过6列。说明文字只保留口径、最大反证和会改变动作的限制。
- “本档增加”“完成后累计”“估值支持累计”“本次实际新增”必须分开。当前可执行仓位只给一个明确值；条件额度不得冒充当前动作。
- 未提供组合金额时只输出百分比；未提供风险预算、行业额度或相关持仓时写`unknown／待确认`，不得默认为无限额度。
- 每个建仓档必须同时满足价格与基本面条件。价格触及不等于自动买入；压力价格不是止损价。
- 基本面退出和估值兑现退出每次都必须出现，即使当前空仓或尚未触发。

## 1. 状态栏与一句话结论

首行固定为：

```text
quick_refresh／earnings_update／full_rebuild｜基本面截止：YYYY-MM-DD｜价格：YYYY-MM-DD及延迟状态｜证券｜币种
```

下一行必须用一句话写明：质量是否合格、当前估值档、当前动作的唯一百分比、最主要未解锁条件，以及当前持仓是否为用户事实或`0%（假设）`。

## 2. 核心决策总览

| 现价／日期 | 质量分／日期 | 核验PR | 执行PR | 归一化估值位置（÷E，1.0＝高估） | 当前动作／新增 |
|---:|---|---:|---:|---|---:|
|  |  | 当前TTM PR | 决策PR |  | **唯一百分比** |

紧接一张纵向核心指标表，避免把十余项指标挤进横向总表：

| 核心指标 | 数值 | 口径／状态 |
|---|---:|---|
| PE_TTM／ROE_TTM |  | 同截止日、股份与会计口径；平均权益方法 |
| 中性／悲观归一ROE（ROA） |  | ROA只作杠杆与资产效率复核 |
| 中性／悲观PR |  | 中性＝情景诊断，悲观＝深档硬闸门；都不是动作线 |
| 基准／熊市EPS |  | 预测年度与事实／假设标签 |
| 杜邦主驱动 |  | 利润率／周转率／杠杆及复核状态 |
| 纯现金下限／严格净金融资产覆盖率 |  | 非金融企业必填 |

使用股东回报修正时并列基础PR与修正PR。ROE超过40%、ROA需要修正、周期股或金融企业适用专门路径时，在本表下增加对应的窄表，不得把重要口径藏在段落中。

周期股固定追加：

| 当前PB／日期 | 完整周期归一化ROE／**执行PR** | 当前运行率ROE／PR | 悲观ROE／PR | 锚分歧率／状态 | 周期位置／当前动作限制 |
|---:|---:|---:|---:|---|---|
|  |  |  |  | aligned／material_gap／regime_split／insufficient | structural_decline／neutral／upturn_confirmed／forecast_only／insufficient |


`material_gap`仅在其他闸门和执行PR均合格时允许最高4%信息风险首仓，并锁定后续档；`regime_split`的当前新增固定为0%，空仓等待，已有持仓默认减仓一半并进入估值退出复核。

|---|---:|---|---|---|
| 目标公司 |  | 龙头／强／中性／弱及依据 |  |  |
| 代表同业 |  |  |  |  |

列3–6家代表同业。基本面角色先由行业地位、经营和资产负债表确定，不能按跌幅倒推；价格层只判断先跌、先稳、行业广度和首仓时点。表后用一句话给出`bear_leading／unconfirmed／bottoming_candidate／recovery_confirmed／insufficient`，并说明该层不改变质量、价值价格带或目标仓位。

## 4. 建仓阶梯

每家公司单独一表：

| 档位／价格区间／执行PR | 本档增加 | 完成后累计 | 必须同时满足 | 当前状态 |
|---|---:|---:|---|---|
| 首仓 `PR≤0.50` |  | 4%–6% | 价格＋基本面＋同业时点＋风险约束 | 已进入／未到价／待确认／暂停／禁止 |
| 主要加仓 `PR≤0.40` |  | 10%–15% | 另含悲观PR `≤0.50` |  |
| 深度价值 `PR≤0.30` |  | 20%–35% | 悲观PR `≤0.40`，排除价值陷阱，超20%需全部硬条件 |  |

价格区间按“下限≤上限”排列，并在价格单元格内显示相对当前价到上限／下限的跌幅。当前已在区间内写`0%（已进入）`；低于整个区间写`已低于区间`。周期股同一单元格显示中性／悲观目标PB和产业周期信号要求。

周期盈利锚为`material_gap`时，主要加仓及更深档的当前状态统一写“锚分歧待确认”；为`regime_split／insufficient`时所有新增档写“暂停／禁止”。这只改变动作许可，不修改原目标PB或执行PR。

如果当前已进入主要加仓或更深档，仍须把“估值支持累计仓位”与“本次实际新增仓位”放进下一张仓位形成桥，不能把累计额度写成一次性动作。

## 7. 两类退出

### 基本面退出

| 触发条件 | 状态判断 | 动作 | 恢复条件 |
|---|---|---|---|
| 经营或现金流减弱 | weakened | 暂停加仓／按压力上限减仓 |  |
| 核心论点、治理或偿债破坏 | broken | 禁止加仓，启动退出评估 |  |
| 关键指标恢复 | intact | 恢复正常持有或重新取得加仓资格 | 必须按最新事实重估 |

### 估值兑现退出

表前显示历史有效峰值样本数、平均／中位PR、样本置信度、`S/H/M/E`的口径。退出价格须使用最新EPS、ROE和股份数重算，不得当作永久挂单价。

| 价格／触发PR | 阶段 | 累计减仓参考 | 执行条件 | 当前状态 |
|---:|---|---:|---|---|
| S | 提前复核 | 10%–15% | 公司历史、最新盈利与基本面共同确认 |  |
| H | 历史高点区 | 30%–40% | 同口径复核 |  |
| M（仅H<E） | 加速兑现 | 50%–70% | 高估继续扩大且基本面复核完成 |  |
| E | 市场风险线复核 | 不单独规定 | 不得只凭PR清仓 |  |
| 确认硬退出 | 基本面破坏或多重证据确认明显高估 | 80%–100% | 启动正式退出评估 |  |

## 8. 复核触发器

| 类型 | 触发条件／时间 | 触发后动作 |
|---|---|---|
| 价格 | 穿越建仓／退出边界，或较估值基准价变动默认≥8% | 用新价格重算，不直接解锁仓位 |
| 官方披露 | 财报、盈利预告、指引或重大公告 | 旧价格带失效，滚动EPS／ROE／股份数／PR |
| 基本面 | 核心经营、现金流、治理或偿债指标越线 | 重跑受影响阶段 |
| 同业 | 弱势组止跌状态或行业广度改变 | 只调整首仓节奏 |
| 日历 | 当前、财报前第5个交易日、发布后快审、完整报表复核 | 使用用户时区和日期状态 |

官方尚未公布财报日时，分别列官方日历检查点与监管最迟／合理窗口，不得把历史预计日写成官方日期。财报后只有新执行PR仍在有效档内才加仓；超出档位不追价。

## 9. 来源

| 期间／事实 | 一级来源 | 状态／用途 |
|---|---|---|
| 最新正式财报 | 监管申报／公司IR | 事实截止日 |
| 当前价格 | 交易所／可靠行情源 | 价格日期及延迟 |
| 预测与估值输入 | 正式交接及其来源指纹 | 事实／模型假设 |

默认只列3–5个最重要来源；关键事实就近附来源，避免在正文重复堆链接。

## 多公司与简版

多公司查询时，每家公司完整重复上述决策卡，最后追加一张横向比较表；不得把不同公司的价格带、同业或退出触发混在同一阶梯中。只有用户明确说“简版”时，才压缩为状态栏、核心决策总览、建仓阶梯、仓位形成桥和两类退出。
