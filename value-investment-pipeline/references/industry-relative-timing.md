# 行业同业强弱与领先信号

本参考用于把同业价格行为作为短期建仓节奏的辅助层。核心假设是：行业转弱时，基本面、行业地位或融资能力较弱的公司常先下跌；行业接近阶段底部时，这些弱势股可能因抛压先耗尽而停止下跌，此时基本面更强的行业龙头仍可能处于较慢、较晚的补跌阶段。弱势股先稳、龙头继续跌并不表示龙头变成弱势股，反而可能是龙头接近短期低点的候选信号。该关系并非恒定规律，必须用多只同业、基本面角色和价格顺序共同验证。

## 1. 同业样本

选择10–15只代表同业，优先满足：

- 主营业务、客户需求、成本驱动和行业周期相近；
- 优先同一上市市场和计价币种，跨市场时先处理交易时差与汇率；
- 日均成交额足以形成可靠价格，排除长期停牌、壳股和极端低流动性证券；
- 优先包含8–12只可识别、可交易且无公司特有事件干扰的结构性弱势观察股，并保留一只行业龙头或行业指数作基准。若实际可比弱势股不足8只，仍须列出所有找到且合格的样本、逐只比较并以有效样本数计算止跌比例；只在输出中标示“样本覆盖有限”并降低置信度，不得因数量不足直接标为`insufficient`、`unconfirmed`，也不要求用户批准后才可比较。

不得仅因走势相似就列为同业。个股正在经历财务造假、退市、重大诉讼、控制权变化、私有化或一次性资产重组时，其价格不用于判断行业止跌。

## 2. 先按基本面划分结构性强弱

强势股和弱势股首先是基本面与行业角色，不是当期涨跌幅排名。行业龙头通常属于强势组，但仍须核验其基本面是否保持领先。

强势组优先依据：

- 行业龙头地位、市场份额、品牌或成本优势；
- 更稳定的收入、利润率、ROE／ROIC和经营现金流；
- 更低的资产负债表风险、更强的融资与穿越周期能力；
- 更高的产品不可替代性、定价权、渠道控制力或网络效应。

弱势组优先依据：

- 非龙头或边缘参与者，份额、品牌、渠道或成本地位较弱；
- 盈利波动更大、利润率更低、现金流更差或持续亏损；
- 杠杆、再融资、稀释、库存、减值或治理风险更高；
- 行业下行时更容易丢失份额、被迫降价或压缩资本开支。

结构性角色每次新财报后复核。在基本面证据未变化时，不因某只股票最近跌得少就把它改为强势，也不因行业龙头在末段跌得更多就把它改为弱势。证据不足时角色写`insufficient`，不得用走势反推基本面标签。

## 3. 再观察价格阶段与先后顺序

同时观察20、60和120个交易日，不用单日涨跌定性。至少记录：

- 相对行业指数或同业中位数的20日、60日收益；
- 距20日、60日和120日低点的距离及最近创新低日期；
- 20日均线方向、是否重新站上20日均线；
- 行业广度：样本中站上20日均线和20日收益转正的比例；
- 结构性弱势股首次明显破位、最后一次创新低和停止创新低的日期；
- 行业龙头开始补跌、最后一次创新低以及跌速是否仍在扩大；
- 弱势组相对龙头的强弱是否由继续恶化转为横盘或改善。

价格表现只用于识别周期阶段，不负责定义强弱角色。结构性弱势股可能先大跌后横盘，导致近20日反而比龙头抗跌；行业龙头也可能在末段补跌时成为近20日跌幅最大的股票。这两种情况都不得反转既定的基本面分组。

典型顺序为：

1. **弱势领先下跌**：弱势股先破位，龙头慢跌或暂时抗跌；
2. **抛压转移**：弱势股跌幅收窄或不再创新低，龙头仍在下跌；
3. **龙头低点候选**：弱势观察池中至少40%的有效样本稳定（按`ceil(n × 40%)`取整且不少于两只），龙头继续回落但跌速开始收窄；
4. **行业恢复确认**：龙头也停止创新低，弱势组和行业广度继续改善。

## 4. 状态判定

### `bear_leading`

至少两只结构性弱势同业先于行业龙头明显破位或刷新20日／60日低点，且弱势组仍在扩大跌幅或行业广度继续下降。龙头跌得少只说明补跌可能尚未完成，不作为安全证据。

### `unconfirmed`

结构性角色不清、价格顺序冲突、样本不足，或弱势股仍持续创新低。弱势股仅单日反弹也属于未确认。保留估值计划，不追加择时仓。

### `bottoming_candidate`

同时满足：

1. 结构性弱势观察池中至少40%的有效样本、且不少于两只，连续5个交易日以上未再创20日新低。所需数量按`ceil(有效弱势样本数 × 40%)`计算；被剔除的停牌、低流动性或公司特有事件样本不得计入分母；
2. 弱势组相对行业龙头不再恶化，且至少出现“跌幅持续收窄、低点不再下移、重新站上20日均线”中的一项；
3. 行业龙头仍在回落或晚于弱势组创新低，形成“弱势股先稳、龙头后跌”的末段顺序；
4. 龙头跌速没有继续显著扩大，或已出现日内／短周期抛压收窄；
5. 上述变化不是单只股票的公司特有事件造成；
6. 目标龙头已进入有效估值买入区，且基本面仍为`intact`。

行业广度改善和弱势股重新站上20日均线属于增强证据，但不再是该阶段的绝对前提，因为行业龙头尚在补跌时指数和广度可能仍然偏弱。该状态只把龙头当前下跌标为短期低点候选，并允许解锁正常首仓；不自动解锁主要加仓、深度价值或20%以上的集中仓位。

### `recovery_confirmed`

弱势观察池中至少40%的有效样本连续10个交易日以上不再创新低，行业广度超过50%并继续改善，行业龙头自身也结束短期下降结构。仍按原估值和风险上限执行，不追涨、不上调目标价。

## 5. 仓位映射

- 目标股未进入有效估值区：任何同业状态都只记录，当前新增仓位为0%。
- `bear_leading`：已进入估值区时等待，或在没有其他风险缺口的情况下取正常首仓区间下限。
- `unconfirmed`：不因技术信号增加仓位；是否使用受限首仓仍由基本面、估值和信息风险规则决定。
- `bottoming_candidate`：弱势股已先稳而龙头仍在晚跌时，允许把龙头当前回落作为正常首仓候选，不要求龙头先上涨确认；不解锁更深档。
- `recovery_confirmed`：不额外增加仓位，只取消由行业择时单独造成的压缩。

基本面失败、预测不可用、估值无效或退出监控暂停时，同业止跌不能恢复新增权限。价格和行业信号只能改变“何时买、首笔买多少”，不能改变“值多少钱、最多持有多少”。

## 6. 反误判与复核

- 单日大涨、跌停打开、超跌反弹或一只弱势股站上均线，不足以判定止跌；弱势观察池中不足40%的样本止跌，同样不足以确认；
- 指数权重股上涨但多数同业仍下跌，不算行业广度改善；
- 不得按近20日／60日跌幅直接给公司贴“强势股／弱势股”标签；跌得少不等于基本面强，龙头末段跌得多也不等于基本面弱；
- 弱势股停止下跌后，龙头继续下跌是需要重点观察的正常候选顺序，不得自动归类为行业继续恶化；
- 财报、并购、监管或股东事件造成的个股跳空，先剔除公司特有影响；
- 若龙头先跌、结构性弱势股后跌，或弱势组稳定只是因为停牌、流动性枯竭、跌停限制或公司特有事件，状态标为`unconfirmed`；
- 每次目标股穿越估值边界、弱势同业刷新阶段低点或行业广度变化20个百分点时重算；正式财报后重新确认同业分组。

输出必须分别列出“基本面角色”和“价格阶段”，并给出完整弱势观察池、有效分母、止跌数量／比例、40%门槛、窗口、价格截止日、先跌／先稳顺序、状态、置信度和至少一个反证。样本少于8只时保留全部比较并标示“样本覆盖有限”；只有缺少可靠基本面证据或历史价格时才标为`insufficient`。
