# 一键价值投资分析

接收公司名称或证券代码后，在同一次任务中完成完整研究流水线。不得要求用户逐个调用下游skill，也不得把研究过程放在最终决策之前。

## 全局证据完整性硬闸门

本流水线及全部下游模块都必须遵守：

- 每个正式数值和状态必须来自可追溯的一手资料、仍有效的正式交接，或由已列明输入按既定公式确定性计算；同时保留证券、期间、口径、截止日和来源指纹。
- 不得猜测、补造、插值或把临时估算写成正式评分、EPS、ROE／ROA、市赚率、压力损失、价格带、仓位、同业信号或退出阈值。模型假设必须显著标成“假设／情景”，不能回填事实字段或解锁可执行动作。
- 缺少关键输入时写`null／unknown／insufficient`并降低状态或停止流水线；不得为了交付完整而用貌似精确的数字补空。
- 多份记录冲突时先展示并核验冲突，优先证券一致、口径一致、证据截止日最新且可追溯的正式来源；未解决前不得静默选值、取最高值或覆盖缓存。
- 不得擅自改变固定公式、阈值或档位，包括自行增加`S／H／M`退出档。若要提出新规则，只能单列为不可执行的规则建议，并须用户明确批准后才能写入正式规则。
- 交付前逐项审计数据血缘；发现本轮或缓存含无依据字段时，先撤销该字段、记录修订原因，再重算所有受影响的下游结论。

## 默认增量运行

每次开始先读取[快速模式与公司缓存](references/fast-path-and-cache.md)，检查项目工作目录下的`.value-investment-cache/<市场>-<代码>.json`。**缓存命中只代表可供核验，不代表可直接输出。** 在任何统计、决策卡或固定格式输出前，必须完成“最新性与完整性门”：以官方披露目录核对最新申报标识，并核对当前价格、同业价格日期、预测／估值／退出／仓位交接的截止日、必要字段和会计口径。默认不是重新运行全部下游skill，而是先完成这项核验，再批量刷新目标股、同业、汇率和市场价格：

- 缓存不存在、身份变化、重大治理／审计事件或正式背景交接失效：`full_rebuild`；
- 出现新财报、盈利预告，TTM窗口滚动导致PE／ROE口径变化，或预测／估值交接失效：`earnings_update`；
- 无新基本面信息且交接仍有效：`quick_refresh`，复用正式评分、预测、压力情景和价格带，只重算当前PR、同业强弱、档位和当前动作。

只要最新性与完整性门发现过期日期、缺失字段、来源／会计口径冲突、未解决的高ROE／ROA复核，或任一交接不是可用状态，必须先按影响范围运行`earnings_update`或`full_rebuild`，并重算其全部下游字段；**不得先用旧数值排版，再以“待更新”附注交付。** 重算后仍缺关键输入时，按中止格式输出`0%／insufficient／恢复条件`，而不是补造统计或价格带。

快速模式不得自行生成或修改质量分、预测EPS、归一化ROE／ROA或压力损失。只有“官方变更检查 + 价格／同业刷新 + 缓存完整性检查”都通过后，才可按固定格式输出完整统计。完成全量或增量更新后，把最小结构化交接、来源指纹和失效触发器写回缓存；不缓存财报全文或冗长叙述。可用`scripts/select_refresh_mode.py`验证缓存并选择运行模式。

## 调用下游skills

按顺序使用，但只提取影响决策的交接字段，不生成或拼接下游skill的完整长报告：

1. `company-background-research`：公司身份、业务模型分类、100分质量评分、证据覆盖和研究通行证；对非金融企业同时使用`pure-cash-coverage`。纯科技公司读取不可替代性、可持续成长性和自主议价能力三项完整硬闸门；平台型零售等混合公司只执行平台不可替代性和议价能力附加闸门，成长按所在行业评价。总控必须原样继承该skill最新有效`research_handoff`中的评分、状态、证据截止日和置信度，不得自行重打分、向上取整或用后续估值结果修正质量分。
2. `company-earnings-forecast`：熊市、基准、乐观收入、利润、EPS、ROE与ROA情景；给估值的熊市场景必须拆出未来三个完整财年及资产负债表路径。
3. `company-valuation-calculation`：把预测结果转换为当前估值位置及条件价格带；稳定非周期企业用同截止日、同股份和同会计口径的`PE_TTM / ROE_TTM`作当前主快照，以最近三个可比完整财年ROE等权平均与未来三年基准预测形成中性归一ROE。三年稳定性分为`strict_stable／relaxed_stable／unstable`；仅当严格通过全流水线的合格候选低于用户组合最低需求（默认6只）时，才允许受控放宽，且放宽候选累计仓位不超过15%。当前TTM或三年任一ROE超过40%时，必须检查回购、净资产收缩与杠杆，并用ROA／ROIC／FCF判断是否失真。对非金融企业做杜邦拆解；周期股必须使用PB路径、完整周期阶段平衡中性ROE和弱年份悲观ROE，并把产业周期确认与股票价格择时分开。
4. `fundamental-exit-monitoring`：判断逻辑状态、退出触发器与减弱／破坏压力情景；对已持有资产，使用历轮高点市赚率、公司自身历史分布、最新同口径盈利和基本面状态建立提前兑现与越涨越卖阶梯。A股／美股`1.00`、港股／H股`0.80`保留为必须复核的市场风险线，但不得单独触发机械清仓。
5. `portfolio-position-sizing`：生成首仓、主要加仓、深度价值三档价格与仓位，并执行组合约束。

估值完成后、仓位落地前，必须执行[行业同业强弱与领先信号](references/industry-relative-timing.md)：先按基本面、行业地位和资产负债表划分结构性强势股与弱势股，再单独观察“弱势股先跌、弱势股先稳、行业龙头后跌”的价格顺序。不得用近20／60日跌幅直接定义强弱；行业龙头末段跌得更多仍可保持强势角色。该层只决定已进入有效估值区后的首仓时点和分批节奏，不修改质量分、盈利预测、内在价值、估值价格带或基本面退出状态。

执行细节和各阶段交接要求见 [references/execution.md](references/execution.md)。缓存命中时只读取本次需要刷新的参考与下游skill；不得为复述已验证结论重新加载和运行全部链路。不得用本skill自创的简化判断替代任何下游skill的专业规则；“精简”只精简检索、计算和呈现，不放宽通关标准。

## 默认核心模式

用户未要求“展开”、“完整报告”、“详细过程”或“YAML”时，默认使用核心模式：

- 第一行附`quick_refresh／earnings_update／full_rebuild`、复用的基本面截止日和最新价格日期；快速模式不重复背景介绍。
- 优先取最新年报、最新中报／季报、重大治理公告和当前价格；只在出现红旗、口径冲突或证据不足时扩大检索。
- 下游只传递：通关状态、质量总分及来源日期、基准EPS、同口径`PE_TTM／ROE_TTM／PR_TTM`及平均权益方法、中性与悲观归一化ROE／ROA、杜邦三因素及杠杆复核状态、公司自身滚动PR分位、中性／悲观市赚率及决策权重、市场PR校准系数、当前估值位置、价格带、同业信号、基本面状态、压力损失、仓位与复核触发器。周期股还必须传递周期驱动、公司角色、四阶段标签与证据、阶段平衡中性ROE、弱年份悲观ROE、净资产质量、`cycle_fundamental_signal`及日期、每档中性／悲观目标PB；这些字段不得由同业股票价格信号代填。已持有资产还要传递估值退出阶段、峰值平均／中位PR、个股锚 `H`、提前线 `S`、市场风险复核线（A股／美股`1.00`，港股／H股`0.80`）和各档价格与累计减仓比例。
- 默认答案按决策卡呈现：首行显示运行模式、基本面截止日与价格日期／币种／延迟；随后依次显示一句话结论、核心指标、同业强弱、建仓阶梯或退出阶梯、主要基本面、复核触发、基本面退出、估值兑现退出和主要来源。多公司查询时每家公司重复完整决策卡，最后才可附横向比较表。具体格式见[公司查询固定格式](references/user-company-query-format.md)。
- 不默认展示维度评分明细、完整熊／基准／牛年度表、公式推导、重复的风险表、机器可读YAML或逐步过程。
- 流水线中止时更简：只输出当前0%、中止原因、恢复条件和非执行价格预案；不展开风险预算敏感性，除非用户追问。

用户指定的日常公司查询格式见 [公司查询固定格式](references/user-company-query-format.md)。用户只说“查一下某公司”时默认使用该格式；同时查询多家公司时，每家分别输出一张完整公司卡，不得为节省篇幅省略任一家的退出机制。

## 单命令默认值

用户只提供公司名或代码时直接开始，不因以下信息缺失中断：

- 未提供组合金额：输出仓位比例，不输出金额；
- 未提供单公司风险预算：内部计算0.5%、1%、2%、3%、5%五档敏感性；核心模式只输出仓位建议、对应隐含压力损失和是否待用户确认，详细模式再展开五档；
- 未提供当前持仓：默认该公司当前仓位为0，但明确标为假设；
- 未提供当前股票数量：以5–8只为常态区间，按当前通过全流程且进入买入区的独立低估候选数动态决定，不为凑数建仓；
- 未提供行业或相关持仓：列为尚未验证的组合约束，不伪造为零。

公司身份存在实质歧义时才提问；能通过证券代码、交易所或官方资料消除时自行核验。

## 严格执行闸门

```text
背景调查 pass
  → 纯科技完整闸门／混合平台附加闸门 pass（不适用则跳过）
  → 业绩预测 usable
  → 估值 valid
  → 退出监控 pipeline pass 且允许新增
  → 仓位方案 executable
```

任何一关未通过：停止生成**可执行**后续结论，在结果区写明停止阶段、原因和恢复条件。为了帮助观察，可以继续给非执行性的盈利或价格敏感性和“状态恢复后需重算”的条件预案，但不得伪装成买入建议。后一步的便宜价格不能反向覆盖前一步的质量或治理失败。

### 质量评分唯一来源

- 质量分只来自本次或最近一次仍有效的`company-background-research.research_handoff`；总控不得根据自身浏览印象另算一套分数。
- 同一公司存在多份背景报告时，优先使用证券一致、证据截止日最新且证据覆盖达标的一份，并显示“评分／证据截止日”。不得取多份报告中的最高分。
- 若用户提供的独立背景报告与总控读取结果不同，先报告差异并以可追溯的正式背景报告为准。单命令运行时若不能取得仍有效的正式分数，必须重新运行背景skill；仍不能完成时把评分标为`insufficient`并停止流水线，不得输出“约多少分”、自行估分或以“待核对”占位后继续生成可执行仓位。
- 正式总分保留一位小数，并显示证据截止日；整数等级只能附在精确分数之后，不能代替精确分数。
- 质量分接近最低通关线时，必须把低分维度或临界项传给仓位控制；`pass`只表示允许进入下一关，不等于高质量或允许重仓。
- 先按毛利来源和客户付费理由区分纯科技、混合平台与行业公司，不能把“使用技术”直接等同于科技股。纯科技三项任一低于3分或证据不足时停止流水线；混合平台只要求不可替代性和自主议价能力分别达到3分，成长按行业维度通过。纯科技三项均至少4分且合计至少12分，或混合平台两个附加项均至少4分且行业增长质量至少11/15，才允许进入35%极端集中仓位的后续评估。

### 市赚率必须显示

估值有效时，核心结果必须显示适用口径的市赚率：

- 当前同口径`PE_TTM`、`ROE_TTM`与`PR_TTM`，包括TTM截止日、GAAP／调整后口径和平均权益方法；完整TTM存在时不得使用单季乘四年化；
- 中性归一ROE／ROA、悲观归一ROE／ROA，以及分别对应的市赚率；
- 预测基准市赚率及对应预测年度；
- 若采用股东回报修正，另列修正市赚率；未修正时写明原因；
- 成长股或平台公司必须标注“情景辅助”，不得把预测ROE对应的市赚率写成确定事实；
- PE路径、PB路径不一致时分别显示，不静默平均。
- 显示公司自身至少五年、优先十年的滚动`PR_TTM`中位数、25／75分位与当前分位。长期高于或低于1时解释结构原因，不把统一阈值作为单一否决或许可。
- 非金融企业显示杜邦净利率、资产周转率、权益乘数的TTM值与三至五年中位数；稳定非周期企业额外显示三年ROE等权平均、变异系数和可比性状态。ROE若超过40%，强制显示`roe_reliability`和ROA／ROIC／FCF检查；若主要由回购、过小净资产或杠杆拉高，按正常资本结构重算，将PR降为诊断项并阻止其抬高目标价。ROA只用于判断质量与重构ROE，不直接代入PR公式。
- ROA必须先做口径失真检查：至少核对利润期间与资产期间是否一致、分母是否使用期初／期末平均资产，以及并购、商誉／资产处置、重大融资、A+H发行、重组或会计重述是否使单点资产失真。若发现失真，用户表格必须并列显示“原始ROA、修正ROA、修正原因与可复算公式”，机器交接写入`roa_adjustment`；优先用同口径TTM归母净利润除以与事件路径相容的平均总资产。若未发现需修正事项，明确写“无需修正”，不得为了填栏制造第二个ROA。修正ROA仍只作资产效率与杠杆检查，不直接代入PR公式。
- 条件估值必须显示企业类型对应的历史窗口、弱年份选择、当前弱运行率、历史悲观锚、未来三年熊市场景权重、归一化ROE和ROA；ROA只作杠杆与资产效率检查，不得直接代入市赚率公式。
- 周期股中性历史锚必须是有产业证据支持的完整周期阶段平衡ROE；逐年等权只能在阶段标签不足时作为临时区间，近期加权值只作敏感性。周期股悲观锚继续使用弱年份和熊市场景。缺少完整周期或阶段证据时不得输出可执行单点估值。
- 周期股每档必须显示`目标PB = 目标PR × 归一化ROE² / 100`的中性／悲观PB边界和对应价格；`1PB／0.5PB`只是特定ROE假设下的交叉检查，不得用作统一初筛硬线。
- 中性市赚率用于正常经营下的筛选与首仓层级；悲观市赚率用于压力测试、深档加仓许可和仓位上限。不得仅因悲观口径未进入低估区就淘汰中性口径明显低估且悲观口径仍可承受的公司。
- 用于建仓决策时，不机械固定选中性或悲观。继承估值skill的动态权重：按企业类型设基础权重，中性／悲观PR差距越大则提高悲观权重，再用有证据的行业宏观分调整±5–10个百分点。必须同时显示中性、悲观、权重和决策值；硬压力或基本面减弱时改用100%悲观或暂停，不得用平均稀释风险。
- 每个首仓、主要加仓、深度价值和极端错价价格带都要显示该带对应的市赚率区间及口径；市赚率区间必须与价格带使用同一EPS、ROE和预测年度。
- 周期股另列`cycle_fundamental_signal`与行业同业价格择时状态。前者来自需求、现货／期货价格、库存、开工率、产能出清、资本开支及已落地政策；后者来自弱势同业先跌先稳。两者都不能修改质量分或基础估值，只能按各自规则调整权重与执行节奏。

### 解释估值与仓位的桥接

市赚率只给出候选层级；质量、预测、杜邦／ROA可靠性、压力损失和组合约束共同决定该层级能否成为“估值支持的累计仓位”，并仍不单独决定“今天一次买多少”。核心结果必须依次显示：

1. 当前市赚率对应的候选估值档，以及估值驱动累计仓位；
2. 从零持仓出发的本次新增仓位；
3. 压力情景允许的仓位上限；
4. 质量／置信度、基本面状态、行业相关性、流动性和用户风险预算造成的压缩；
5. 最终采用值与唯一或主要瓶颈。

同业强弱信号位于第2项与第3项之间：目标股尚未进入有效估值档时只记录、不解锁仓位；已经进入估值档但结构性弱势同业继续创新低、行业广度继续恶化时，首仓取区间下限或等待确认；仅当不少于8只有效弱势观察股组成的样本中，至少40%（按`ceil(n × 40%)`取整且不少于两只）先停止创新低、相对行业龙头不再恶化，而基本面更强的龙头仍在晚跌时，才可把龙头自身的短期回落视为接近低点的首仓择时候选。行业广度改善是增强证据而非这一末段信号的绝对前提。具体判定和反误判规则见[行业同业强弱与领先信号](references/industry-relative-timing.md)。

若当前价格已经越过首仓区并进入主要加仓或更深区，不能把“本次新增仓位”冒充为该估值层级的全部仓位。应分别写“估值支持累计至X%”与“本次先新增Y%”；没有风险或基本面瓶颈时，也不得无理由把估值支持仓位压回普通首仓。

若未解锁仓位依赖下一期财报，继承`portfolio-position-sizing`的 [复核时间与财报跳空政策](../portfolio-position-sizing/references/review-and-gap-policy.md)：完整流水线已通过且唯一缺口为下一期经营确认时，可在正常首仓与风险上限内先持有受限首仓；同时设置日历、官方披露和价格三类触发器。必须给出财报前第5个交易日预检、材料发布后2小时内或下次开盘前的快审、完整报表后的首个用户时区工作日复核，以及跳空后按新基本面与新决策PR加仓或不追价的条件。旧目标价在新财报发布后自动失效，不能因害怕踏空沿用。

当用户要求自动监控、每天核查或主动通知时，读取 [references/active-monitoring-plan.md](references/active-monitoring-plan.md)。自动任务提示词必须携带当前目标仓位、基准日期、每只证券的精确8%过期线、全部估值边界、具体复核日历和更新日志字段；每次运行都报告最新可得价格及价格日期，即使没有触发也给简短结果。发现正式财报日时把相应内部日期替换为财报前第5个交易日、发布后快审、完整报表复核和跳空后复核。自动监控不得执行交易，并必须明确手机推送依赖产品及系统通知权限。

## 组合政策

继承`portfolio-position-sizing`的用户政策：

- 单只股票绝对上限35%，这是罕见极端错价下的集中上限，不是常规目标；
- 股票组合常态保持5–8只；候选不足时可低于5只并保留现金，超过8只只在独立的高质量低估机会充分且能降低联合风险时考虑；
- 价格建仓上沿为决策市赚率约0.55：首仓决策PR≤0.55；主要加仓决策PR≤0.50且悲观PR≤0.55；深度价值决策PR≤0.40且悲观PR≤0.50；极端错价决策PR≤0.30且悲观PR≤0.40；
- 所有PR档只是候选线；质量、预测、杜邦／ROA可靠性、压力损失和组合闸门通过后才能成为可执行估值档；
- 当前PR高于0.55时，不因其他估值口径看似便宜而绕过该通道；等待盈利、价格或资本结构变化后重算；
- 上述为A股／美股基础PR阈值；港股／H股所有动作阈值统一乘以`0.80`，即首仓`0.44`、主要加仓决策`0.40`且悲观`0.44`、深度价值决策`0.32`且悲观`0.40`、极端错价决策`0.24`且悲观`0.32`；港股`0.80`是估值退出风险复核线，须结合公司历史、最新同口径盈利和基本面状态复核后才执行减仓；
- 常规首仓4%–6%，主要加仓后累计10%–15%，深度价值且基本面完整时累计20%–30%；
- 35%只用于高确信、深度错价、非公司特有恐慌、压力损失可承受且组合相关性可控的“关键时刻”；
- 每档同时满足价格条件和基本面条件，不因下跌机械加仓。

## 跨市场差异

先确认A股、H股、港股、美股或ADS的股份、币种、汇率、税务路径和流动性。港股／H股执行固定PR市场系数`0.80`：只把基础动作阈值和目标价格乘以`0.80`，不把观察到的PR乘系数。该规则已吸收一般性的税后回报、流动性、汇率和投资者结构折价，仓位不得因相同理由再次乘以`0.80`；只有有证据的证券特有增量风险才能另行压缩。用户的默认同等风险回报排序仍是美股优先于A／港股；A股与港股之间不预设固定顺序，以税后股东回报、估值折价和可交易性决定。

## 交付边界
