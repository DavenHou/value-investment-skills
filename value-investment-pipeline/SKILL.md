# 一键价值投资分析

接收公司名称或证券代码后，在同一任务中完成研究流水线。不要求用户逐个调用下游 skill，也不把研究过程放在最终决策之前。

## 全局证据闸门

- 正式数值和状态必须来自可追溯的一手资料、仍有效的正式交接，或由已列明输入按既定公式确定性计算；保留证券、期间、口径、截止日和来源指纹。
- 不得猜测、补造、插值或把临时估算写成正式评分、EPS、ROE／ROA、市赚率、压力损失、价格带、仓位、同业信号或退出阈值。模型假设必须标成“假设／情景”，不能回填事实字段或解锁动作。
- 缺少关键输入时写`null／unknown／insufficient`并降低状态或停止流水线；不得为了表格完整而补数。
- 多份记录冲突时先展示并核验冲突；未解决前不得静默选值、取最高值或覆盖缓存。
- 不得在总控中改写下游的固定公式、阈值或档位。新规则只能作为不可执行建议，待用户明确批准后再改动其唯一责任文件。
- 交付前审计数据血缘；发现无依据字段时撤销该字段，并重算所有受影响的下游结论。

## 闭环完成

- 以公司名／代码调用时，在已选请求范围内一次完成闭环，不把可由公开资料或既定口径完成的重建任务交回用户；`quick_valuation`不生成仓位，`full`才包含仓位。
- 出现非经常项目、税前／税后缺口、历史峰值口径不一致或缓存过期时，按[execution.md](references/execution.md)重建当前 TTM、三年情景、历史峰值及所选范围内的下游字段。
- 若正式材料只披露税前非经常项目，可用同期`所得税费用 ÷ 税前利润`作标准化税后敏感性；必须与原始 GAAP 并列，标成模型口径。正式决策口径以估值 skill 为准，不用敏感性数值替换。
- 只有在一手资料客观不可得且无法形成可复算输入时才中止；届时只显示`0%／数据不足`和缺少的原始字段，不继续展示旧价格带或恢复步骤。

## 先选择增量模式

每次先按[快速模式与公司缓存](references/fast-path-and-cache.md)确定“请求范围＋刷新深度”，再按该文件指定的范围读取对应缓存并保存结果；本入口不复制其路径、条件表或快算格式。

用户只说“跑一下”，或仅给公司名／代码调用本 skill 时，默认使用`scope=quick_valuation`；“快算、只算估值、估值和退出”同样进入该范围。它在内部保留最新财务／TTM、纯现金覆盖、三年预测、归一化ROE／ROA、杜邦可靠性、估值、压力与退出计算，只跳过公司背景、质量评分、同业和仓位；默认对用户只展示“核心决策卡＋估值价格带”。只有用户明确说“完整跑一下、完整分析、全流程、从头完整研究”等完整意图时才使用`scope=full`。用`scripts/select_refresh_mode.py --scope ...`校验缓存；历史`--as-of`必须拒绝估值日之后的预测、TTM、价格和退出证据。

## 运行流水线

严格按顺序读取正式交接，只传递会改变决策的字段：

0. **前置快筛**（仅限新建仓；**已有持仓复查不走此步**）：`PB > 8` 则停；非周期股`核验PR = PE_TTM ÷ ROE_TTM > 0.50`则停，`ROE_TTM ≤ 0`时不适用，**周期股禁用 0b**。
1. **质量闸门**：`company-background-research`原样交接`research_handoff`，不在总控重新打分；非金融企业同时运行`pure-cash-coverage`。
2. `company-earnings-forecast`：读取三年熊／基准／牛情景及可用状态。
3. `company-valuation-calculation`：读取当前估值、价格带、盈利能力可靠性和估值交接。
4. `fundamental-exit-monitoring`：读取基本面／估值双状态、压力损失和退出阶梯。
5. 在估值与仓位之间执行[industry-relative-timing.md](references/industry-relative-timing.md)；它只影响首仓时点和分批节奏，不修改质量分、预测、估值或目标仓位。
6. **仓位**：`portfolio-position-sizing`计算分层仓位、组合约束及可选凯利上限。用户要求“旧规则 vs 新规则”时，直接使用该 skill 的`rule_comparison`，不在总控另造对照逻辑。

上述是**五步流程**：前置快筛→质量闸门→估值→退出→仓位；盈利预测、同业信号是正式中间输入，不另设动作线。非周期股执行ROE按估值 skill 的选档、下滑保护与保守取低规则消费正式交接；港股市场系数及买卖两端刻度也以估值 skill 为准，总控不复制公式。

阶段交接、估值分支、高 ROE 复核、稳定性受控放宽、港股动态`c`校准、压力损失和一致性检查全部以[execution.md](references/execution.md)及各下游 skill 为唯一执行来源。总控只负责编排，不复制实现规则。

## 严格执行闸门

```text
背景调查 pass
  → 纯科技完整闸门／混合平台附加闸门 pass（不适用则跳过）
  → 业绩预测 usable
  → 估值 valid
  → 退出监控 pipeline pass 且允许新增
  → 仓位方案 executable
```

任一关未通过：先完成可公开检索或可复算的补齐；仍缺少原始输入才停止可执行结论。后一步的便宜价格不能反向覆盖前一步的质量、治理或数据失效。

## `full`范围的默认输入与输出

用户只提供公司名或代码时直接开始：

- 未提供组合金额：输出仓位比例，不输出金额；
- 未提供单公司风险预算：内部计算`0.5%／1%／2%／3%／5%`敏感性，核心模式只显示建议仓位、隐含压力损失及是否待确认；
- 未提供当前持仓：默认为`0%`并明示标为假设；
- 未提供持股数：以`5–8只`为常态区间，按实际全流程合格候选决定，不为凑数建仓；
- 未提供行业或相关持仓：标成未验证组合约束，不伪造为零。

公司身份存在实质歧义时才提问；能由代码、交易所或官方资料消除时自行核验。

输出使用[公司查询固定格式](references/user-company-query-format.md)；估值字段和买卖六档直接复用[估值输出结构](../company-valuation-calculation/references/output-schema.md)，本 skill 不另存一份 schema。`full`范围的建仓表分开显示本档增加、完成后累计、同步条件和当前状态；多公司查询时每家保留完整决策卡，最后再比较。`quick_valuation`默认只显示核心决策卡和估值价格带；三年预测、纯现金覆盖、杜邦、压力情景、历史样本、复核触发器和来源仍在内部计算与审计，仅在用户明确要求展开，或某项缺口会改变决策有效性时，把限制写入固定模板中最相关的“判断”单元格，不另起章节或新增行。

周期股在核心指标后固定追加完整周期归一化ROE／执行PR、当前运行率PR、悲观PR与盈利锚分歧表。执行PR是唯一动作线，由估值 skill 的第二公式及所选档正式归一ROE交接确定；其余情景PR只作诊断，与执行PR的差额必须写出。历史峰值比较须用峰值日当时形成的同口径预测。`material_gap`最多允许4%信息风险首仓并锁定后续档；`regime_split`新增为0%，已有持仓默认减仓一半并启动退出复核。

流水线中止时只显示当前`0%`、中止原因和缺少的原始字段。未经用户要求，不展开评分明细、公式推导、重复风险表或机器 YAML。

依赖下一期财报确认时，执行[review-and-gap-policy.md](../portfolio-position-sizing/references/review-and-gap-policy.md)；用户要求自动监控时再读[active-monitoring-plan.md](references/active-monitoring-plan.md)。


## 模型分工

体量较大时先读 `model-routing`：先跑 `select_refresh_mode.py` 选增量模式，再决定哪些采集工作派给便宜模型。子代理只回传原始数字和来源，所有状态字段、口径选择、阈值判定和仓位数字由主会话判定。

## 交付边界

输出研究判断和条件化仓位建议，不执行交易、不创建订单、不把压力价格当止损价。当前市场和公司资料必须标明截止日期，事实、预测假设和用户风险偏好分别标识。
