# 纯现金覆盖率

本技能回答一个核心问题：**扣除有息负债后，公司的确定现金以及一年内低风险流动金融资产，分别能够覆盖当前市值的多少？**

这不是自由现金流指标，而是资产负债表指标。每次分析必须同时计算并展示**确定下限**和**严格净金融资产口径**，不得用财经网站直接提供的“净现金”、清算价值、净流动资产或含经营租赁的替代指标取代。

## 证据完整性硬闸门

- 每一项计入或扣除金额、期限、受限状态、底层资产性质、股数和ADS比例都必须有可追溯依据；不得根据科目名称、网站“净现金”或行业惯例补造明细。
- 无法确认资产是否一年内、未受限且低风险时不得把未经核实的上界写成正式严格口径；应给已核实下界或区间，并把未确认部分明确留空。
- 口径冲突时保留计算桥和差异来源，未解决前不得静默选择覆盖率更高的数字，也不得让估算覆盖率通过30%硬门槛。

## 固定公式

对非金融企业始终计算以下两套结果：

```text
确定下限净金融资产
= 可自由支配现金及现金等价物
- 有息负债

严格净金融资产
= 可自由支配现金及现金等价物
+ 公司列为流动资产的一年内、未受限、低风险金融产品及短期投资
- 有息负债

确定下限每股价值 = 确定下限净金融资产 ÷ 实际经济流通普通股数
确定下限每 ADS 价值 = 确定下限每股价值 × 每 ADS 代表的普通股数
严格净金融资产每股价值 = 严格净金融资产 ÷ 实际经济流通普通股数
严格净金融资产每 ADS 价值 = 严格净金融资产每股价值 × 每 ADS 代表的普通股数
确定下限覆盖率 = 确定下限净金融资产 ÷ 当前市值
严格净金融资产覆盖率 = 严格净金融资产每股价值 ÷ 当前股价
                       = 严格净金融资产 ÷ 当前市值
```

**确定下限**只反映现金能够确认的最低安全垫。**严格净金融资产口径**是主要筛选指标，必须纳入符合要求的一年内流动金融资产。两套结果必须并列展示，不能用确定下限替代严格口径。

资产负债表采用公司最新报告期，股价采用最新可取得的正式收盘价。显著写明两个日期，不得无说明地混用。

## 可计入资产

确定下限只计入未受限的现金及现金等价物。

严格口径额外计入符合以下全部条件的金融资产：

- 公司将其列为流动金融资产；
- 到期日不超过一年；
- 未被质押、冻结、托管或限制使用；
- 公司未披露重大的本金损失风险。

通常可以计入：

- 货币市场基金、国库券、短期可交易证券及明确披露的交易性金融资产；
- 一年内银行理财、结构性存款、短期定期存款和短期投资；
- 其他可在一年内到期、赎回、出售或转换为现金，且预计不会造成重大本金损失的流动金融产品。

不得计入：受限现金、托管资金、法定准备金、客户托管资金、质押存款、贷款应收款、应收账款、存货、预付款、固定资产、无形资产、商誉、长期投资以及战略性或私募股权投资。

不要仅凭“以公允价值计量且变动计入损益的金融资产”“其他投资”或“货币资金”等科目名称直接计入，必须核对底层资产性质。

不得仅因原始期限超过三个月或管理层计划持有到期，就排除其他条件均合格的资产。只要仍属于一年内到期的流动资产、未受限且无重大本金风险，就计入严格净金融资产，但不计入确定下限。

如果公司把一年内定期存款、低风险理财和短期投资合并在同一个流动资产科目，只要披露的组成部分符合上述条件，就把整个合并科目计入严格净金融资产，不得仅因公司没有进一步拆分而整项剔除。如果能确认其中包含受限资产、超过一年资产、战略股权投资或重大估值风险资产，则剔除可识别的不合格部分，并说明仍未解决的不确定性。

## 有息负债

必须扣除：短期借款、一年内到期的有息债务、银行贷款、票据、债券、可转换债券，以及具有融资和利息性质的融资租赁负债。

不得扣除：应付账款、应付票据、递延收入、合同负债、客户预付款、预计负债、应交税费及其他普通经营负债。

经营租赁负债不属于本公式。金额重大时可以作为固定成本和经营风险单独披露，但不得从确定下限或严格净金融资产中扣除。只有用户明确要求时，才另外计算含经营租赁的压力测试，而且不能用压力测试替代两套固定结果。

递延收入不是有息负债，不得机械扣除；但金额重大时必须解释其为什么会限制现金的可分配性，并提醒本指标不等于清算价值。

本公式不适用于银行、保险、券商、基金等资产负债表型金融机构，不得用客户存款与部分金融资产简单相减。

## 研究流程

1. **确定范围。** 核实公司、证券代码、ADS 换算比例、币种、股价日期、最新报告期，并确认其属于非金融经营企业。
2. **优先使用一手资料。** 阅读业绩公告、监管文件、年报、资产负债表附注、回购披露及投资者关系网站。股价和成交额可使用可靠行情来源。所有重要财务数字都要给出来源。
3. **建立可核对的计算桥。** 逐项列出计入和剔除的资产、负债及理由，不得直接采用网站的“净现金”结果。
4. **核对分母。** 使用实际经济流通股数，不得使用每股收益中的加权平均股数。计入经济权利相同的全部普通股类别，扣除库存股和已注销股份。ADS 必须核实换算比例并计算等效股数。
5. **计算两套结果。** 先报告确定下限净金融资产、每股或每 ADS 价值及覆盖率；再报告严格净金融资产、每股或每 ADS 价值、市值及覆盖率。最后一步才四舍五入。
6. **进行质量复核。** 检查最近十二个月盈利、经营现金流、自由现金流、收入或订单趋势、净金融资产变化、递延收入、资本配置、公司治理及二十日平均成交额。
7. **区分事实和判断。** 先给出原始计算，再单独讨论资金可及性、客户预付款、VIE 或跨境资金限制、控制权等因素。不得偷偷把主观折价塞进公式。

## 筛选规则

默认范围为上市非金融经营企业。银行、保险、券商、基金、特殊目的收购公司及尚无收入的生物科技公司不进入主名单，可在单独标注的特殊机会附录中展示。

必须分层筛选，不能把盈利能力悄悄变成第一轮过滤条件。

| 层级 | 默认规则 | 用途 |
|---|---|---|
| 资产筛选 | 严格净金融资产覆盖率不低于 30%；用户要求时提高到 40%；同时说明确定下限是否达标 | 寻找具有资产支撑的候选公司 |
| 流动性筛选 | 二十日平均日成交额不低于 1,000 万美元，除非用户另设门槛 | 保证实际可交易性 |
| 质量筛选 | 盈利、现金消耗、业务趋势、资本配置和治理 | 用于风险排序和仓位判断，不得删除已通过资产筛选的候选公司 |

结果分类：

- **核心价值候选：** 盈利或能够产生现金，净金融资产稳定或增长，并且存在可信的分红或注销式回购。
- **资产支撑型反转：** 覆盖率高，但当前利润或经营现金流较弱；必须量化现金消耗和可支撑时间。
- **价值陷阱观察：** 业务快速收缩、净金融资产持续下降，或管理层缺少可信的价值释放路径。
- **排除：** 资产受限或质量差、流动性不达标，或者会计模式导致本指标不可比。

## 资金可及性与治理

公式衡量资产负债表，不代表小股东能够要求管理层立即分配现金。以下项目必须单独检查：

- 已经实际执行的回购、平均回购价格，以及股票是否注销；
- 已经实际支付的股息，而不是只有授权；
- 控股股东投票权和多层股权结构；
- 境外控股、VIE、境内外资金转移限制及现金所在地；
- 关联交易、异常收购、资产出售或股权稀释。

给出清晰的**资金可及性评级**：

- **A：** 持续分红或重大注销式回购，公司治理透明。
- **B：** 已经有一定资本返还，但管理层仍有较大自由裁量权。
- **C：** 现金长期留存且缺少可信释放路径，或存在明显法律、控制权限制。
- **D：** 小股东取得这些现金的可能性高度不确定。

除非用户明确要求情景分析，不得把评级换算成貌似精确的百分比折价。

## 定期复查模板

开头先给一句状态结论：**逻辑成立／逻辑减弱／逻辑破坏**，并说明核心原因。

| 项目 | 本期 | 上次复查 | 方向与解释 |
|---|---:|---:|---|
| 可自由支配现金及现金等价物 |  |  |  |
| 一年内低风险金融产品及短期投资 |  |  |  |
| 有息负债／另行披露的经营租赁 |  |  |  |
| 确定下限净金融资产及覆盖率 |  |  |  |
| 严格净金融资产及覆盖率 |  |  |  |
| 两种口径的每股或每 ADS 价值 |  |  |  |
| 实际股本和股价 |  |  |  |
| 收入或订单、净利润、经营现金流、自由现金流 |  |  |  |
| 递延收入或客户预付款 |  |  |  |
| 回购、分红及注销情况 |  |  |  |
| 流动性和治理风险 |  |  |  |

出现以下任一情况时，立即重新评估：

- 净金融资产出现重大下降，且不是用于明确的股东回报；
- 连续两个报告期经营显著恶化或现金消耗加速；
- 管理层停止执行价值释放计划、增发稀释股份，或进行缺乏解释的关联交易和战略投资；
- 递延收入、退款、监管或债务义务使表面现金难以使用；
- 流动性或上市地位显著恶化。

股价下跌本身不会破坏投资逻辑。股价上涨导致资产折价消失时，应重新按正常经营企业估值，但不构成机械卖出信号。

## 输出要求

除非用户要求其他语言，否则使用中文。必须包括：

1. 公司范围、报告期、股价日期、币种及数据截止时间；
2. 并列展示**确定下限**与**严格净金融资产口径**，包括计算桥、每股或每 ADS 价值、当前市值及两种覆盖率；
3. 当前交易流动性和资金可及性评级；
4. 质量与风险提示，重点包括递延收入、现金消耗及净金融资产变化；
5. 简短结论，明确区分“通过资产筛选”和“具备投资质量”。

不得给出针对用户个人的买卖指令、目标价或确定性结论。只有用户明确要求仓位建议时，才以风险预算示例的方式讨论。
