# 极限参考价与质量分仓位上限设计

日期：2026-09-13

## 目标

取消“破坏场景压力损失”对建仓仓位和加仓许可的机械约束，只保留一个极限参考位置供心理、现金和组合波动准备；同时把固定35%单股上限改为由正式质量评分决定的阶梯上限。

## 决策规则

### 1. 极限参考只展示

- 继续用可追溯的破坏情景输入计算极限参考价或区间。
- 固定展示相对现价跌幅、相对计划加权建仓成本跌幅，以及按最终建议仓位计算的组合净值影响。
- 明确标注：极限参考不是预测价、目标价或止损价。
- 极限参考、极限跌幅和用户风险预算不进入最终仓位 `min(...)`，不压低估值支持仓位，不阻断任何价格档。
- 删除单公司风险预算敏感性和“完整阶梯持仓浮亏不超过50%”可行性闸门。

### 2. 质量分决定单股绝对上限

| 正式质量分 | 单股绝对上限 |
|---:|---:|
| `<60` | `0%`，质量闸门不通过 |
| `60–69` | `10%` |
| `70–79` | `20%` |
| `80–89` | `30%` |
| `90–100` | `35%` |

- 只接受 `company-background-research` 输出的正式、仍有效质量分，不估分、不四舍五入跨档。
- 正式质量分缺失、过期或不可验证时，质量上限为 `unknown`，不得输出可执行新增仓位。
- 质量分上限由 `portfolio-position-sizing` 唯一定义；其他 skills 只传递质量分或消费计算结果。

### 3. 最终仓位形成

```text
最终仓位上限 = min(
  质量分单股上限，
  行业上限，
  相关组上限，
  流动性上限，
  账户或监管上限
)

最终建议仓位 = min(估值支持累计仓位, 最终仓位上限)
```

缺失的组合约束保持 `unknown`，不默认成100%；没有适用值时从 `min(...)` 中省略，但必须披露缺口。极限参考不在公式中。

## 保留的硬约束

- `fundamental_status=broken` 或投资逻辑已被证伪：禁止加仓并启动退出。
- 审计、治理、现金归属、偿债、证券身份、估值不可用等证据闸门保持不变。
- 行业、相关性、流动性、账户和监管约束保持不变。
- 估值档位、基本面同步条件以及 `S/H/M/E` 退出框架保持不变。

## 接口与迁移

- 将用户界面的“压力价格／压力损失／压力风险上限”改为“极限参考价／极限跌幅／建议仓位下的组合影响”。
- 旧缓存只要依赖压力仓位上限、风险预算或50%阶梯闸门即失效并重算，避免旧字段继续暗中压仓。
- 悲观盈利预测和下行敏感性继续用于基本面核查与估值解释，但不再转化为压力仓位上限。
- 不增加配置开关或双模式；本规则直接取代原压力仓位约束。

## 涉及范围

- `portfolio-position-sizing`：公式、质量阶梯、输出结构和测试。
- `fundamental-exit-monitoring`：极限参考计算与语义，保留真实基本面破坏退出。
- `value-investment-pipeline`：编排、决策卡、缓存失效条件与测试。
- `company-valuation-calculation`：只调整向下游交接的压力约束语义；保留悲观估值与基本面敏感性。

## 验收条件

1. 任意极限跌幅变化都不会改变最终建议仓位或加仓许可。
2. 质量分 `59/60/70/80/90/100` 分别得到 `0/10/20/30/35/35%` 上限。
3. 正式质量分缺失时不会补造上限或给出可执行新增仓位。
4. `fundamental_status=broken` 仍固定禁止加仓。
5. 所有决策卡明确显示极限参考及其非预测、非止损、非仓位约束属性。
6. 现有四组价投脚本测试通过，并新增覆盖上述行为的最小测试。
