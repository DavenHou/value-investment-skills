# 中性／悲观情景动态权重

本规则用于建仓决策口径，解决“中性市赚率与悲观市赚率差距较大时不应机械只取一边”。两个原始情景必须始终并列展示；动态权重只形成决策参考，不得隐藏分歧或跨PE／PB路径混合。

## 1. 基础权重

下表是组合风险控制的默认政策，不是市赚率公式或原始周期股文章推导出的结论。周期股的中性输入必须先是完整周期阶段平衡ROE，不能因这里悲观权重较高而再把中性ROE改成弱年份ROE。

| 企业类型 | 中性 | 悲观 | 理由 |
|---|---:|---:|---|
| 稳定价值／品质消费 | 55% | 45% | 正常经营的可预测性较高，仍保留接近一半的下行权重 |
| 科技／结构性成长／混合平台 | 50% | 50% | 增长和终值分歧通常较大 |
| 金融 | 40% | 60% | 信用和资产质量尾部风险更重 |
| 周期／困境反转 | 35% | 65% | 峰值盈利容易造成虚假便宜 |

## 2. 情景差距修正

先计算：

```text
差距率 = (悲观PR - 中性PR) / 中性PR
```

悲观PR原则上应高于中性PR。若反向，先查EPS、ROE、股本、会计口径或路径错配，不直接加权。

| 差距率 | 权重调整 |
|---|---|
| `≤10%` | 不调整 |
| `>10%–25%` | 中性向悲观转移10个百分点 |
| `>25%–50%` | 中性向悲观转移20个百分点 |
| `>50%` | 中性向悲观转移30个百分点；首仓上限4%，低置信时暂停 |

## 3. 行业与宏观修正

用最新可溯源证据给行业运行状态评分 `-2／-1／0／+1／+2`。至少检查下列四类证据，并写明日期与来源：

1. 终端需求、订单、销量或客户预算；
2. 定价、促销、毛利率和单位经济；
3. 库存、产能、供给出清或渠道周转；
4. 利率、汇率、原材料、政策或资本开支周期中真正能改变该公司盈利的项目。

周期股把上述证据汇总为独立的`cycle_fundamental_signal`：

- `deteriorating`：需求、价格／价差、库存／产能等多项继续恶化；
- `mixed`：证据方向冲突或仅个别指标企稳；
- `bottoming`：至少两类领先产业指标停止恶化，但盈利修复尚未完整确认；
- `recovering`：至少两类领先指标改善，且订单、价格／价差或行业利润中至少一项已兑现；
- `insufficient`：缺少可比、及时或可追溯证据。

现货／期货、订单、库存、开工率、产能退出和已落地的供给政策属于产业信号；同业股票价格的先跌先稳属于择时信号。二者必须分别记录，股票信号不得给`cycle_fundamental_signal`加分。`insufficient`按行业宏观分0处理并降低置信度，不得当成`bottoming`。

| 行业宏观分 | 含义 | 权重调整 |
|---:|---|---|
| +2 | 多项同向改善，且有领先指标确认 | 悲观向中性转移10个百分点 |
| +1 | 温和支持 | 悲观向中性转移5个百分点 |
| 0 | 混合、中性或证据不足 | 不调整；证据不足必须标注，不得假设为利好 |
| -1 | 温和不利 | 中性向悲观转移5个百分点 |
| -2 | 多项同向恶化，且有领先指标确认 | 中性向悲观转移10个百分点 |

最终中性权重限制在20%–70%，悲观权重限制在30%–80%。若出现已确认的行业硬压力、流动性冲击、信用事件或`fundamental_status: weakened/broken`，不使用权重平均稀释风险：直接使用100%悲观口径或暂停新增。

不得重复惩罚同一风险。若熊市EPS／ROE已经显式纳入某项利率、汇率或需求冲击，行业宏观分只调整该情景发生的权重，不再对EPS或ROE做第二次折减。

## 4. 决策值与价格带

```text
决策PR = 中性权重 × 中性PR + 悲观权重 × 悲观PR
```

价格带不直接用“平均ROE”或“平均EPS”代入，而是先在各情景内计算同一目标PR `T`的价格，再按权重合成：

```text
PE路径的目标价格 = T × (中性权重 × EPS中性 × ROE中性百分数点
                         + 悲观权重 × EPS悲观 × ROE悲观百分数点)

PB路径的目标价格 = T × (中性权重 × BVPS中性 × ROE中性² / 100
                         + 悲观权重 × BVPS悲观 × ROE悲观² / 100)
```

必须并列展示中性价格、悲观价格和加权价格。当差距率超过25%时，额外显示差距来源和权重变化，不只输出一个加权点。

周期股还必须逐情景列出每个目标`T`的公司专属PB边界：

```text
中性目标PB = T × 中性归一ROE² / 100
悲观目标PB = T × 悲观归一ROE² / 100
```

`1PB／0.5PB`只在对应归一ROE约为15%／10%且`T≈0.5`时成立，不得替代上述计算。

## 5. 分层动作约束

- 首仓：决策PR `≤0.55`，且基本面许可。
- 主要加仓：决策PR `≤0.50`，同时悲观PR `≤0.55`。
- 深度价值：决策PR `≤0.40`，同时悲观PR `≤0.50`。
- 极端错价：决策PR `≤0.30`，同时悲观PR `≤0.40`，并通过所有集中度与基本面硬闸门。

这些阈值决定“估值支持的累计仓位”，不等于今天一次买入的仓位。实际新增仍取风险预算、业绩确认、组合相关性、流动性和单股硬上限的最低值。
