# 输出结构

一张表。结论先行，过程在后。

## 必须出现在第一屏

| 字段 | 说明 |
|---|---|
| 当前动作 | 首仓／主要加仓／深度价值／不到买点／减仓／清仓／`insufficient` |
| 本次新增仓位 | 百分比区间，已过 `min(质量分上限缩放后的档位额度, 35%)` |
| 决策PR | 周期股 `100×PB÷执行ROE²`；非周期 `PE_TTM÷执行ROE` |
| TTM扣非净利润同比／重大业绩下滑保护 | 显示估值脚本的同比与触发状态；触发时说明已切换至悲观预测，缺数据或基期异常时保留原状态文本 |
| 归一化估值位置 | `决策PR ÷ E`，1.0＝高估线；并注明 `governed_by`（raw_pr 还是 normalized） |
| 买入三档价格 | `≤0.50 / ≤0.40 / ≤0.30` 对应价 |
| 卖出三档价格 | 归一化 `0.80 / 0.90 / 1.00` 对应价 |
| 最坏情况 | 跌到深度价值线（可加仓段）与跌到悲观情景价（真实损失段），各附组合拖累 |

## 必须随后给出

| 字段 | 说明 |
|---|---|
| 执行ROE 及其来源 | 列股息率、选中预测档位、所选档正式归一ROE、当前TTM及最终绑定项；触发重大业绩下滑保护时标明覆盖 |
| 8PB 闸门 | `clear / blocked / pb_unknown`，附当前PB |
| 校准项全清单 | `E_market`、`N = clamp(50/D,1,2)`、买入线市场系数——**未触发的也要打印并写明原因** |
| 核验PR | `PE_TTM ÷ ROE_TTM`，仅作数据自查 |
| 历史峰值PR | 值、出现时点、是否可复算；不可复算时标 `insufficient` 并说明卖出线偏宽 |
| 质量分 | 分数、档位、证据覆盖度，未做时标 `insufficient` 且当前新增 0% |
| 计算护照 | 规则版本、价格日、财务截止日、TTM EPS三段实际值来源、TTM净利、同日权益、回购滚动窗口起讫及金额、执行ROE候选与绑定项、`calculation_basis_id` |
| 输入截止日与数据源 | 价格日期、最新可得报告期、汇率 |
| 缺口清单 | 哪些输入是占位假设，补齐后可能改变哪一档 |

## 硬性禁止

- 不得以资料搜集过程、公司背景、公式推导或长篇风险提示开场
- 不得要求读者看完计算过程才能找到结论
- 缺数据时写 `insufficient` 并说明影响，不补造数字
- 不得并列第二条动作PR
- 非周期动作线不得使用前瞻／指引／预测EPS，不得混用不同截止日的利润、权益或回购
