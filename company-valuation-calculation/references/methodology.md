# 市赚率计算方法

## 1. 变量与单位

- `PE_TTM`：估值日价格或市值除以同一股份口径最近四季度稀释后EPS或可比归母净利润。
- `PE`：非TTM或归一化情景下的市盈率倍数，必须另注期间。
- `PB`：市净率倍数。
- `R`：ROE的百分数点，例如31%记作`31`。
- `r`：ROE的小数形式，例如31%记作`0.31`，所以`R = 100r`。
- `D`：多年平均股利支付率的百分数点，例如30%记作`30`。
- `PR`：市赚率。本资料也曾被转写为“市转率、P2、P1”，初稿统一写作`PR`。

所有计算保留未四舍五入结果，展示时再统一保留两到三位小数。

## 2. 基础公式与TTM对齐

稳定价值股的TTM核验快照必须写成：

```text
核验PR = PE_TTM / ROE_TTM百分数点
ROE_TTM = 最近四季度可比归母净利润 / 同期平均归母净资产
TTM稀释EPS = 最新完整财年稀释EPS - 上年同期YTD稀释EPS + 本期YTD稀释EPS
```

`核验PR`只做数据自查，不是动作线。非周期股的正式`决策PR`、执行ROE取低集合、正常资本重算和计算护照只以[scenario-weighting.md](scenario-weighting.md)的“截止日锁定计算”为准。`PE_TTM`、`ROE_TTM`和`TTM稀释EPS`必须同截止日、同股份类别、同会计口径；前瞻EPS、指引EPS和预测EPS不得代入。

**ROE_TTM 的默认取值方法（与原始资料一致）：把最近四个单季度的净资产收益率直接相加。** A股可用同花顺 F10 → 财务 → 单季度 → 净资产收益率取数。例：中远海控 2026Q1 2.51% + 2025Q4 1.80% + 2025Q3 4.02% + 2025Q2 2.47% = 10.80%。这是作者实际使用并公开演示的方法，也是使用者能自行复核的方法。

只有当单季ROE不可得，或存在重大股本变动、增发、回购使单季相加失真时，才改用五个连续季末归母净资产按`(E0/2 + E1 + E2 + E3 + E4/2) / 4`做季度时间加权的替代口径，并**显式标注使用了替代口径及两者差异**。两种口径在高回购或高增发公司上可能相差数个百分点，不得混用。正式主值使用未扣非的GAAP／法定归母净利润；决策PR及价格带沿用同一口径，不能因决策卡标签或扣非数值可得而切换。调整后值仅作单列核验，必须成对重算PE与ROE并列明调节项；重大一次性项目未解释清楚时暂停正式价格带，不以调整后值暗中替换。有完整TTM时不得用单季乘四年化。TTM只降低季节性和期间错配，不消除周期、一次性项目、净资产骤缩或数据滞后。详细规则见[杜邦拆解与ROE可靠性](dupont-and-roe-reliability.md)。

**重大业绩下滑保护**：另取最近连续四季与上年同期四季的扣非净利润合计，按`(当前TTM－去年同期TTM) ÷ |去年同期TTM|`计算同比；触发阈值只以`scripts/calculate_valuation.py`的`MAJOR_EARNINGS_DECLINE_THRESHOLD`为准。触发时在现有ROE选择前强制使用正式悲观预测／悲观归一ROE，优先于任何股息率选档；缺少悲观交接时不输出决策价。四季数据不足时显示“数据不足，无法判断”且不触发；去年同期TTM扣非净利润不大于零时显示“基期异常，无法使用正常同比判断”且不触发。此指标只作预测档位保护，不替换正式决策PR所用的法定归母利润口径。

**股息率预测选档**：按估值价格日已公告的最新股息率选正式归一ROE：大于6%用乐观，大于5%且不大于6%用中性，其余用悲观；边界为严格“大于”。重大业绩下滑保护触发时覆盖为悲观。股息率缺失时沿用审慎悲观档；若悲观交接也缺，旧式裸算例仅标为`unselected`诊断，不构成正式选档。所选档位缺少正式预测交接时标`insufficient`，不猜数、不静默换档。具体比较阈值只以`scripts/calculate_valuation.py`中的常量为准。选档只换预测情景及对应归一ROE，不改PR、目标价格、市场系数或股东回报系数的公式。

### PE路径：ROE稳定的价值股

```text
PR_PE = PE / R
      = PE / r / 100
```

例：`PE=14.7，R=31`，则`PR=14.7/31=0.474`。

### PB路径：周期股、困境反转或需要归一化ROE的对象

由`PE = PB / r`推导：

```text
PR_PB = 100 × PB / R²
      = PB / r² / 100
```

例：`PB=0.96，R=15.88`，则`PR≈0.381`。

当`PR=1`时，名义合理倍数为：

```text
PE_fair = R
PB_fair = R² / 100
```

因此ROE为10%、15%、20%时，名义合理PB分别为1、2.25、4倍。

### 只有PE和PB时的等价交叉公式

如果PE与PB来自同一日期、同一股份和同一财务口径，可由`R = 100 × PB / PE`得到：

```text
PR_PE_PB = PE² / (100 × PB)
```

这只是代数交叉检查。PE或PB失真、利润为负、净资产异常时不得使用。

## 3. 股东回报修正

对主要依靠现金分红回报股东的稳定价值股，资料以50%多年平均股利支付率为基准，并把修正系数限制在1至2之间。

**适用闸门（MIGRATION_NOTES 第 24 条，2026-09-15）：只有股息率 > 4% 的红利股才适用 N。** 股息率 ≤ 4%（含完全不分红）的公司不在本修正的射程内，`N = 1.0`——这是"不适用"，不是"罚满"。周期、科技（回购替代分红）、成长股一律不用。

股息率按估值价格日已公开的**最新分红方案**核算：列明纳入分子的每笔现金派息、公告日和除息日；已公告但尚未除息的特别分红须计入最新已公告股息率，并注明其未除息状态，不能只取最近一次常规年度派息，也不能把不同年度的同类特别分红重复相加。行情软件的已支付 TTM 股息率若采用另一时间窗口，另列其口径核对。用于 `N` 的可持续股利支付率仍从正常年份取数，剔除未证实可持续的特别分红；除息后同步刷新股价与股息窗口。

```text
股息率 ≤ 4%  ->  N = 1.0                      # 非红利股，不适用
股息率 > 4%  ->  N_raw = 50 / D
                N = min(2, max(1, N_raw))

PR_adjusted = N × PR_base
```

加上 4% 闸门后，N 只在「股息率 > 4% 且支付率 < 50%」时真正触发，等价于 `PE < 12.5`——银行股的形状，与资料中"比较茅台、美的和银行"的出处一致。

- 股息率 ≤ 4%：`N=1`（不适用）。
- `D ≥ 50`：`N=1`。
- `D ≤ 25`：`N=2`。
- `D ≤ 0`（不分红）：`N=1`，**不是 2**。机械按股息 `D=0` 算出 `N=2` 是忽略回购的错误读数。
- `25 < D < 50`：例如`D=30`，`N=1.667`；`D=40`，`N=1.25`。

修正后的PR越高，代表在同样盈利与ROE下，低现金回报使估值显得更贵。股利支付率应使用多个正常年份的现金股利／归母净利润，剔除不可持续的特别分红并解释亏损年份。对美股或主要依赖回购返还资本的公司，改用：

```text
净回购 = 现金回购 - 员工股权激励及其他发行带来的股本增加
总股东支付率 = (现金股利 + 净回购) / 可持续归母净利润
```

优先用稀释后流通股数的多年变化交叉检查净回购是否真正使每股权益上升。如果回购只是抵消SBC稀释，不得把回购总额全部当成股东回报。

**修正系数 N 的适用边界（原始资料明确排除）——只适用于 ROE 稳定的价值股：**

| 企业类型 | 是否使用 N | 原始理由 |
|---|---|---|
| ROE稳定的价值股 | **使用** | 现金分红是主要回报形式，50%支付率可作标杆 |
| 周期股 | **不使用** | 萧条年份无钱可分，支付率不可比 |
| 科技股 | **不使用** | 经常用回购代替分红 |
| 成长股 | **不使用** | 需要留存利润用于成长 |

唯一例外：**周期股进入景气周期多年之后仍不舍得加大分红**，此时才对该周期股使用修正市赚率 `PR = N × 100 × PB / R²`。原始资料的实例是中煤能源H股与中国海油H股——基础市赚率看仍略微低估，修正市赚率看已经高估。

其余情况一律 `N = 1`，不做修正。无法把回购与股权激励稀释分开的公司同样不修正。

## 4. 目标倍数与目标价格

在其他输入不变时，PR与价格、PE和PB近似线性。对任一目标`T`：

```text
目标价格 = 当前价格 × T / 当前PR
非周期股同义式 = 实际目标PR × 执行ROE × TTM稀释EPS
```

若使用修正PR，就必须用修正PR计算目标价格；不得把基础PR与修正目标混搭。

未修正口径下：

```text
目标PE = T × R
目标PB = T × R² / 100
```

修正口径下：

```text
目标PE = T × R / N
目标PB = T × R² / (100 × N)
```

### 8PB 硬约束（原始资料的独立经验线）

原始资料在市赚率之外给出了一条**独立的、市赚率本身无法解释的**经验线：

> 巴菲特还有一个 8PB 魔咒，市赚率也无法解释。买入市净率超过 8PB 的投资案例均不太成功，投资收益远低于平均水准——宝洁、卡夫亨氏、IBM、迪亚极欧、以及 2026 年的谷歌定增均是如此。

这条线与市赚率的关系可以精确求出：`PR=1` 时合理PB `= R²/100`，令其等于 8 得 `R = 28.28%`。下表说明 ROE 越高，市赚率标尺允许的PB 越离谱：

| ROE | PR=1 对应PB | 该PB 是否被 8PB 禁止 |
|---:|---:|---|
| 15% | 2.25 | 否 |
| 20% | 4.00 | 否 |
| 28.28% | 8.00 | 临界 |
| 40% | 16.00 | **是** |
| 50% | 25.00 | **是** |

**但 8PB 只作用于建仓端，不改写估值刻度。** 正确用法是一条独立闸门：

```text
若 当前PB > 8 → 不得建仓（无论决策PR 多低）
```

曾经写成 `E_eff = min(E_market, 800/R²)` 的做法已废止。把一条经验买入禁令换算成PR 刻度，会把高ROE股的整条卖出梯按比例压扁，产生"原始PR 0.29 属深度价值、归一化 0.60 属中段"的自相矛盾读数（Deckers 2026-09 即是此例）。高估线的真正上界是**个股自己的历史峰值PR**，见 `scenario-weighting.md` 第 5.1 节。

ROE > 40% 仍须叠加 `extreme_roe_review_required` 的财技复核（回购、净资产收缩、杠杆），但那是分母可靠性问题，与 8PB 无关。8PB 本身只有一条判断：**当前PB > 8 不建仓**。

资料中的股票经验区间为`0.4、0.5、0.6`低估观察区，`1.0`名义合理／高估分界。它们只是框架经验标尺，必须与公司自身同口径历史分布、同行、盈利质量、未来三年情景和杜邦结构共同使用，不能机械下单。

## 5. 分支口径

### 归一化ROE与ROA

市赚率公式只使用ROE。ROA是独立交叉检查，用来识别债务、回购、商誉减值或净资产收缩是否把ROE机械抬高。逐年先计算：

```text
ROE_i = 可比经常性归母净利润_i / 平均归母净资产_i
ROA_i = 可比经常性归母净利润_i / 平均总资产_i
```

历史和预测年份均先统一会计口径、股份范围与一次性项目，再计算年度比率。重大增发、回购、并购或资产剥离年份必须使用当年时间加权平均权益与资产；无法重建时把该年降权或剔除并说明。经济性亏损必须保留，不得把负值改成零。

默认估值先构造唯一历史悲观锚：

```text
历史弱年份集合 = 历史窗口内ROE最低的约40%年份（至少2年）
历史弱年份ROE = 弱年份按越近权重越高的加权平均
历史弱年份ROA = 同一批年份的ROA加权平均
当前弱运行率 = min(最新完整年度, 可比TTM)
ROE锚来源 = min(历史弱年份ROE, 当前弱运行ROE)
ROA锚 = 与所选ROE锚完全相同来源和期间的ROA
归一化ROE = 历史块权重 × 历史悲观ROE锚 + 预测块权重 × F1–F3熊市ROE加权值
归一化ROA = 历史块权重 × 历史悲观ROA锚 + 预测块权重 × F1–F3熊市ROA加权值
```

并列计算中性口径。稳定价值股中性与悲观共用上述历史悲观锚；中性只把预测块换成基准情景：

```text
稳定非周期企业历史诊断ROE = 最近三个可比完整财年ROE等权平均（仅用于稳定性与对照）
技术／结构性成长企业历史中性ROE锚 = 历史窗口内ROE按越近权重越高的加权平均
周期股历史中性ROE锚 = 低谷、复苏、景气、回落四阶段各自平均值的等权平均
历史中性ROA锚 = 与ROE完全相同年度、阶段和权重的ROA
稳定价值股中性归一ROE = 50% × 历史悲观ROE锚 + 20% × F1基准ROE + 20% × F2基准ROE + 10% × F3基准ROE
稳定价值股乐观归一ROE = 50% × 历史悲观ROE锚 + 20% × F1乐观ROE + 20% × F2乐观ROE + 10% × F3乐观ROE
稳定价值股悲观归一ROE = 50% × 历史悲观ROE锚 + 20% × F1熊市ROE + 20% × F2熊市ROE + 10% × F3熊市ROE
稳定价值股ROA使用与ROE完全相同的锚来源、年份和权重
其他企业类型的乐观／中性／悲观锚与权重仍按各自分支执行
```

稳定价值股的乐观、中性与悲观口径固定共用同一历史悲观锚50%，预测块固定50%；仅F1–F3预测情景分别使用乐观、基准与熊市。最近三年等权ROE均值保留为稳定性与历史对照，不再进入正式中性归一公式。三档均须按上文股息率规则与重大业绩下滑保护选取；悲观口径仍用于压力测试、深档加仓许可和仓位上限。中性与悲观ROE相差超过25%，或中性ROE高于当前可比运行率超过25%时，必须展示区间与差异来源。

### 决策PR（唯一动作线，公式按类型选择）

动作线只有一条，公式、执行ROE 窗口与输入截止日规则以 [scenario-weighting.md](scenario-weighting.md) 为准：

```text
周期股／困境反转：决策PR = 100 × 同期PB / 执行ROE²
非周期股：        决策PR = PE_TTM / 执行ROE

执行ROE：按 scenario-weighting.md 的同类型取低集合选择
实际高估线 E_eff = min(E_market, 个股历史峰值PR)   # 8PB 不参与，它只禁建仓
```


同一公式必须能在每个历史峰值日用当时可得数据复算，否则该轮进入剔除清单。周期股历史峰值还需该峰值日已形成且可追溯的三年熊市预测；缺少时不用该轮峰值，`E`回退市场线。不得用今天的预测或峰值之后才披露的利润、事后重述回填历史峰值PR。

周期股还必须在同日PB下做“盈利锚分歧检查”，把当前运行率与跨周期假设分开：

```text
当前运行率PR = 100 × 当前PB / 当前弱运行ROE²
决策PR = 100 × 当前PB / 执行ROE²
悲观PR = 100 × 当前PB / 悲观归一ROE²
锚分歧率 = (三者最大PR - 三者最小PR) / 三者最小PR
```

当前运行率PR与悲观PR都不是动作线：前者只用于分歧检查，后者只用于深档硬闸门、压力测试和仓位上限。

三者必须使用同一股份类别、估值日、会计口径和平均权益方法。当前弱运行ROE只能使用可比TTM与最新完整年度的较低者；单季、半年度简单年化或把预测年度混入历史均值只能列为非执行敏感性。

`cycle_anchor_conflict`按以下顺序判定：

1. 任一必要输入缺失或不可比：`insufficient`；
2. 任一锚的PR达到市场风险复核线`E`，同时另一锚达到首仓阈值 `0.50`（全市场同值）：`regime_split`；
3. 未发生方向分裂，但锚分歧率`>50%`：`material_gap`；
4. 其他：`aligned`。

**买入阈值基础值 `0.50／0.40／0.30`，与市场系数 `c` 相乘后与原始读数取更严；高估线 `E_market = c`，再与个股历史峰值PR 取小。买卖两端共用同一个 `c`（第 23 条）。8PB 不进入 `E`，它只是一条 `PB > 8 时不得建仓` 的独立禁令。**

`material_gap` 只在其他硬闸门和决策PR均合格时允许最高4%的信息风险首仓，不解锁主要加仓或更深档；`regime_split` 暂停新增，空仓输出`wait／0%`。

**已有持仓遇到 `regime_split`（两种ROE假设给出割裂结论）时，默认动作是减仓一半。** 这是原始资料中远海控案例的明确结论——第一方案（TTM ROE 10.80%）显示A股0.977、H股0.866 已经高估，第二方案（多年平均ROE 14.59%）显示A股0.535、H股0.474 仍然低估，作者的处置是"卖出半仓，即便有可能卖飞，也要遵守纪律"。减半是纪律性默认值，不是需要额外论证的例外；只有当用户有税务、流动性或最低核心仓要求时才调整比例，并必须写明理由。`material_gap` 不触发减半，只提高复核紧迫度。该闸门只调整动作许可，不反过来修改决策PR、目标PB或情景权重，避免同一分歧被重复惩罚。

稳定股3年窗口取较弱2年，科技股5年窗口取较弱2年；周期股正式悲观锚改取最近5个可比完整财年中ROE最低的一年。其他诊断仍可展示10年弱4年。ROA必须沿用ROE所选年份和来源，不能分别挑最低值后拼成现实中不存在的组合。当前运行率有可比TTM时与最新完整年度取低；单季或半年度年化只能列为非执行敏感性。

周期股取最低单年前先重建经常性可比口径，剔除纯会计性且不可重复的异常；真实经济亏损、反复发生的减值、周期低谷和结构性恶化必须保留。最低年度ROE≤0时，第二公式不能因平方而给出伪便宜价格，标`non_actionable`。历史普通近期加权均值仍需展示为对照；若悲观锚较普通加权值低超过25%，标记复核原因并优先输出区间。

默认使用未来三个完整财年的乐观、基准与熊市场景。预测来自`company-earnings-forecast`的逐年净利润、平均归母净资产与平均总资产；如果上游只给净利润而没有资产负债表路径，不得伪造预测ROE／ROA。

默认窗口与权重如下。历史按“最早→最近”排列，预测按“第1年→第3年”排列；表中百分比是总权重。

| 企业类型 | 中性历史锚 | 悲观历史锚与块权重 | 乐观／基准／熊市预测三年权重 | 选择理由 |
|---|---|---|---|---|
| 稳定价值／一般非周期 | 最近3个可比完整财年ROE等权平均只作稳定性诊断 | 近3年取弱2年，并与当前弱运行率取低；三档历史块均50% | 乐观／基准／熊市F1/F2/F3均为20%、20%、10% | 三档共用历史悲观锚，分别接入对应预测 |
| 周期股／困境反转 | 覆盖完整周期，低谷／复苏／景气／回落四阶段等权 | 最近5个可比完整财年最低ROE；悲观历史块70% | 各档F1/F2/F3：15%、10%、5% | 股息率选档后进入第二公式，当前TTM更弱时再取低 |
| 科技／结构性成长 | 近5年近期加权 | 近5年取弱2年，并与当前弱运行率取低；历史块50% | F1/F2/F3：25%、15%、10% | 业务变化快，历史低端与熊市预测各半 |

周期股正式悲观归一ROE = 70% × 最近5个可比完整财年最低ROE + 15% × F1熊市ROE + 10% × F2熊市ROE + 5% × F3熊市ROE。中性／乐观档沿用本分支历史锚和预测权重，换入对应情景；`执行ROE = min(所选档正式归一ROE, 当前可比ROE_TTM)`；没有可比TTM时只用前者并标明。70/30是本框架审慎默认值，不是经验最优权重；60/40可列非执行敏感性，不能静默替换正式值。周期预测的中等置信度沿用本分支降权规则，低置信度不混合且不给可执行决策PR。

其他分支的权重按各自规则执行。调整规则：

- **稳定价值**：最近三个可比完整财年ROE的算术平均仅用于稳定性分级和历史对照。正式中性形式为`50% × 历史悲观锚 + 20% × F1基准ROE + 20% × F2 + 10% × F3`；正式悲观只把F1–F3换成熊市ROE。稳定性是分级筛选条件，不是绝对硬闸门：
  - `strict_stable`：三年ROE全为正值、变异系数`CV≤25%`，且业务范围、会计口径和资本结构无重大可比性断点；
  - `relaxed_stable`：只有当严格通过全流水线的候选数低于用户组合最低需求（未指定时为6只）才启用。要求三年ROE仍全为正值、`CV≤40%`、最新年ROE不低于三年均值的70%，且业务／会计／资本结构可比；
  - `unstable`：`CV>40%`、任一年ROE不为正、最新年ROE低于三年均值70%，或可比性断点未解决。不使用稳定股单点PR；只有符合业务属性时才改走成长／周期分支，否则估值为`conditional／non_actionable`。

  放宽只放宽ROE稳定性，不放宽质量、治理、预测可用性、高ROE财技复核或悲观情景。`relaxed_stable`只允许普通首仓与主要加仓，在至少两期后续正式财报重新确认为`strict_stable`前，累计仓位不超过15%，不解锁深度价值档或20%以上的集中层。必须分别报告严格池数量、放宽新增数量和放宽原因；放宽后仍不足时保留现金，不得继续扩张标准。不足三个可比完整年度时不得使用本路径。
- **周期股**：十年必须至少包含一次“低谷—复苏—景气—回落”。阶段划分须引用产品价格、销量／订单、库存、产能利用率、行业利润或公司毛利率等证据，不能根据股价倒推。每阶段先在阶段内平均，再把四个阶段等权；同时展示历史逐年等权和近期加权值作敏感性。未覆盖完整周期时最长扩展至15年；若仍缺阶段，或十年前的产能、监管、业务结构已失去可比性，只能使用结构变化后的至少5年并把中性锚标为`provisional`，不输出可执行单点。阶段平衡值与逐年等权或近期加权值相差超过20%时输出区间、解释周期长度偏差，不选最乐观值。
- **科技股**：只有不可替代性、成长持续性和自主议价能力闸门通过时才混合预测。研发费用、SBC、股本稀释和并购形成的无形资产必须统一处理；闸门未通过或熊市预测无法形成资产负债表路径时，市赚率只能标为不足以估值。
- **预测置信度**：稳定价值股的正式中性与悲观口径固定为历史50%/预测50%；中等置信度只降低结论置信标签，不改权重。周期股高置信默认历史70%/预测30%；中等置信度把预测块降为默认值的75%（历史77.5%/预测22.5%）。低置信度不混合历史与预测，只并列展示并把估值标为非执行性。其他企业类型按各自分支调整预测块。

先按同口径杜邦拆解ROE，再计算简化的杠杆放大倍数：

```text
ROE_TTM = 归母净利率_TTM × 总资产周转率_TTM × 权益乘数_TTM
```

```text
Leverage_multiplier = ROE_normalized / ROA_normalized
```

至少报告净利率、资产周转率、权益乘数的TTM值、三至五年中位数和变化方向；数据允许时再做五因素杜邦。若权益乘数或该倍数较历史中位数偏离超过25%，ROE上升而ROA／ROIC下降，或债务与利息覆盖同步恶化，先查债务、回购、资产减值和净资产收缩。若ROE主要由杠杆抬高，用历史正常权益乘数与压力融资成本重算中性／悲观ROE；无法解释时采用较低ROE情景、设置`leverage_review_required`并停止输出单点PR。净现金很多的轻资产公司也可能出现较低ROA，应结合经营资产回报检查，不能机械处罚。金融企业改用监管资本与资产质量体系。

### ROE超过40%的强制财技复核

当前`ROE_TTM`或最近三个可比完整财年任一ROE超过40%时，设置`extreme_roe_review_required=true`。这是强制复核线，不是高ROE奖励线。必须核对：

- 现金回购总额与稀释后股数净变化，区分真正净回购与只抵消SBC稀释；
- 平均归母净资产是否因长期回购、特别分红或减值而过小甚至为负；
- 回购是否由新增债务融资，权益乘数、净负债和利息覆盖是否恶化；
- `ROA_TTM`、最近三年等权ROA、ROIC、每股自由现金流是否与ROE同向改善；
- 用历史正常权益乘数或正常资本结构重算后，ROE还剩下多少。

复核后标记`roe_reliability=organic_high_return | usable_with_caution | buyback_or_leverage_distorted | insufficient`。只有高ROE同时由高净利率／高周转、健康ROA／ROIC、低或稳定权益乘数和每股现金流支持时，才能保留ROE主路径。像长期大额回购压缩净资产使ROE飙升的公司，即使业务优质，也必须把`PR_PE/ROE`降为`diagnostic_only`；使用历史正常权益乘数或正常资本结构重算ROE。无法可靠重算时估值为`conditional／non_actionable`。ROA用于判断盈利质量和重构ROE，不得直接把`ROA`塞进`PE / ROE`或`100 × PB / ROE²`公式冒充新的PR。

可用`scripts/calculate_normalized_profitability.py`生成权重并复算。周期股用`--historical-phases`按最早到最近逐年传入`trough,recovery,boom,downturn`标签；缺少标签时只能作临时诊断，`roe_pr_executable=false`。周期股正式悲观锚用最近五年最低值，不按年份加权；熊市预测内部权重为15%/10%/5%。60/40只作为非执行敏感性。

### 稳定价值股

当前主快照展示同日、同口径的`PE_TTM`、`ROE_TTM`与`PR_TTM`；正式乐观、中性和悲观归一ROE／ROA均使用历史悲观锚50%+未来预测50%，分别接乐观、基准和熊市F1–F3，年度总权重均为20%/20%/10%。最近三年等权ROE均值只作稳定性与历史对照。先报告三年ROE逐年值、等权平均、标准差、变异系数、可比性和`strict_stable／relaxed_stable／unstable`分级；受控放宽候选须显示候选稀缺证据、仓位限制和重新确认日历。至少检查过去五年ROE波动、非经常性损益、商誉减值、股本变化、分红覆盖和杜邦结构。

### 周期股与困境反转

先确认周期属性：公司盈利、利润率或ROE必须对产品价格、订单／销量、库存、开工率、产能利用率或客户资本开支呈可验证的周期敏感性。再按成本曲线、市场份额、低谷现金流、债务和产能纪律把公司标为`leader／mainstream／high_cost_tail／uncertain`；`high_cost_tail`或`uncertain`不得仅凭低PB进入可执行估值。

**周期股 ROE 取值的第一原则：尽量保守。** 原始资料的原话是"在估值周期股时，ROE 的取值需要尽量保守才行"。原始材料中的景气期低年、完整周期多年平均与阶段平衡值继续并列为历史诊断；正式第二公式采用上文最近五年最低值与熊市预测的组合：

1. **景气周期里 ROE 最低的一年**。原始资料的中远海控案例用 2023 年的 11.80% 作保守估值；锂矿案例用景气第一年的动态ROE。这是历史参照，不替代最近五年正式锚。
2. **覆盖完整周期的多年简单平均**。中石油案例用 1999–2002 四年平均 15.88%；资源股用 2020–2025 一轮完整萧条加景气的平均值。
3. 四阶段（低谷／复苏／景气／回落）等权平均，用于中性归一诊断，须有产业证据明确标注阶段。

**资源型周期股使用多年平均ROE 的前提是储量或产能可持续**（原始资料：中石油案例"储量丰富是前提，所以中海油更适用"）。储量枯竭、产能退出或资产不可穿越低谷时，多年平均失去意义，只能用当前弱运行口径。

使用当前PB搭配正式执行ROE；悲观归一ROE同时用于压力测试和深档硬闸门。ROE证据优先顺序：

1. 有产业证据标注阶段的完整周期阶段平衡值；
2. 多个可比完整周期的中位数或保守分位数；
3. 缺少阶段标签时的完整周期逐年等权值，只作临时区间；
4. 新周期已有证据时，使用景气第一年的保守ROE作情景，不当作事实。

除决策ROE与悲观锚外，固定显示当前弱运行ROE及其PR，并执行上述`cycle_anchor_conflict`。完整周期归一化ROE回答“正常跨周期盈利能力是多少”，当前运行率回答“如果当下较弱盈利延续会怎样”，两者不得互相覆盖，也都不得替代决策PR。

另行检查`cycle_fundamental_signal`，至少覆盖四组产业证据：①终端需求／订单／销量；②现货或期货价格、价差、毛利率；③库存、开工率、产能退出和资本开支；④已经落地而非只停留在口号的供给侧或“反内卷”政策。状态为`deteriorating／mixed／bottoming／recovering／insufficient`并记录证据日期。它只调整中性／悲观权重、首仓时点和分批节奏，不改写ROE、质量分或基础目标PR；股票同业先跌先稳属于另一套择时信号，不能代替产业确认。

每个目标PR均计算公司专属`目标PB = T × R² / 100`和目标价格。资料中的粗略启发式是：ROE约15%的行业龙头在`PR=0.5`时目标PB为`1.125`倍，可近似观察“1PB”；ROE约10%的主流企业在`PR=0.5`时目标PB为`0.5`倍。两者只作速查交叉验证，不是分类依据或跨行业硬筛选线。还必须检查净资产质量：库存跌价、固定资产与在建工程利用率、商誉、资源储量／资产可采性、减值、少数股东权益和有息负债；低PB由不可回收资产造成时停止机械估值。

### 成长股与科技股

默认并列输出：近5年近期加权历史与未来3年基准情景各50%形成中性归一ROE／ROA；近5年较弱2年历史悲观锚与未来3年熊市场景各50%形成悲观归一ROE／ROA。平台型零售等混合公司若业务变化速度接近结构性成长公司，可使用该窗口，但按行业而非纯科技成长闸门评价。再投资回报、研发资本化、回购、股权激励和终值未处理时，结论必须标成低置信度或不足以估值。

### 金融企业

市赚率只能是表层估值。银行至少补充净息差、不良与拨备、资本充足率；保险补充内含价值、投资收益与准备金；券商补充周期化盈利与资本约束。

### 指数

指数的PE、PB和ROE必须来自同一编制方、同一日期和相同加权方式。

- 红利／质量指数：原始资料把A股`PR≈1.0`视为高估观察值。
- 宽基指数：资料认为成分混有成长股，单一PR适用性较弱，并把标普500、沪深300的`PR≈1.5`作为高估经验值。

上述均为案例校准，不是内在价值定理。

## 6. 税负与跨市场校准

原始资料把长期持有的股息税近似映射到高估阈值：

```text
税后高估阈值 = 基准高估阈值 × (1 - 税率)
```

例如基准`1.0`、税率20%得到`0.8`；宽基基准`1.5`、税率20%得到`1.2`。该算式是历史启发式，不作为所有市场的统一税率公式。实际税率仍取决于投资者身份、账户、上市地、持有期和交易路径。

跨市场规则用同一个市场系数 `c` 同乘**买入线与高估线**（第 23 条，取代原始资料只调高估线的分档写法）：

```text
港股／H股   c = 0.90 × (1 − 股息率 × t ÷ 10%)      # t: 港股通个人股息税，H股 20%、红筹/开曼 20%（28% 作敏感性）
A股／美股   c = 1.00                               # t=0，0.90 是港股专属折价，不得外溢

E_market = c
买入线   = 0.50／0.40／0.30 × c                    # 与原始决策PR 两个读数取更严
E        = min(E_market, 个股历史峰值PR)
归一化估值位置 = 决策PR ÷ E
指数另表：恒生 1.35、恒生国企 1.20、A股红利 1.00、宽基 1.50
```

`0.90` 是港股的流动性、汇率与投资者结构折价，与股息无关；括号内是股息税拖累占 10% 基准长期回报的比例。旧的离散分档 `0.80／0.72` 相当于股息率 5.56%（t=20%）的红利股，对低股息港股是过度惩罚。

**买入线基础值为 `0.50／0.40／0.30`（比资料中的四折五折六折各严一档），并与市场系数 `c` 相乘后与原始读数取更严**（MIGRATION_NOTES 第 23 条，2026-09-15）。

此前两度反复，记录在案：2026-09-13 校准第 3 条以"无原始依据"废止了买入线乘 `0.80`；2026-09-15 重新引入，理由不同——**不是为了再加一道门槛，而是为了让买卖两端落在同一把尺子上**。若只有卖出线乘 `c`、买入线不乘，归一化刻度上首仓位置变成 `0.50 ÷ c`（快手 0.58、特步 0.67），到清仓线 `1.00` 只剩 1.72／1.49 倍，市场折价单方面吃掉了持有区间。两端同乘之后，首仓价 × 2 恰好等于清仓价，"买 0.5 卖 1.0"才成立。本条同时消除源码内部矛盾：`scenario-weighting.md` §5.2 本就写"两个读数取更严"。

A+H 两地上市的公司以 H 股为标杆：H股达到其高估线后，A股一并卖出。

当前观察到的PR 本身永远不乘任何系数。退出风险线必须结合公司自身历史、最新同口径盈利和基本面状态复核，不能单独触发清仓。动态`c`已吸收一般市场折价，仓位层不得再因同一市场标签重复下调；证券特有的额外风险必须有证据并单列。具体规则见 [cross-market-calibration.md](cross-market-calibration.md)。

## 7. 一致性与停止条件

- 可执行估值必须有一个企业类型适配、输入同口径的主路径，并完成公司自身历史、未来三年情景、杜邦／ROA可靠性检查。任一关键输入不可比时为`conditional／non_actionable`。
- 公司自身至少五年、优先十年的滚动`PR_TTM`中位数和25／75分位只用于校准。长期高于或低于1必须解释结构原因，不能把统一阈值当作单一否决或许可。
- `PR_PE`与`PR_PB`明显不一致时，先检查ROE分母、平均净资产、TTM期间、少数股东权益和一次性利润。
- 高ROE复核未完成、正常资本结构ROE无法重算、三年预测不可用或压力损失缺失时，不得输出可执行仓位；应保留可验证价格带并列出补证条件。
- PE为负或无意义、ROE≤0、净资产接近零或为负时，不输出PR。
- 跨币种不影响倍数本身，但价格目标、每股净资产和市值必须统一币种与股份换算。
- 只要核心输入是猜测，就用区间和敏感性分析，不给单点“合理价”。
