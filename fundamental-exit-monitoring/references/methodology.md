# 基本面退出监控方法

## 1. 状态对象

基本面状态和估值状态分别判断：

```text
基本面：成立 → 减弱 → 破坏
                 ↘ 证据不足

估值：安全边际仍在 → 接近合理 → 已兑现或偏高
                         ↘ 无法可靠估值
```

基本面状态回答“原投资逻辑是否仍然成立”；估值状态回答“当前价格是否仍补偿风险”。两者可以形成不同组合，例如“基本面成立＋估值已兑现”或“基本面减弱＋表面低估”。

## 2. 投资断言结构

每条核心断言记录以下字段：

| 字段 | 含义 |
|---|---|
| assertion | 可以被事实推翻的投资判断 |
| metric | 最能验证该判断的经营或财务指标 |
| baseline | 建立记录时的数值、期间与来源 |
| expected_path | 基准情景下的方向或区间 |
| tolerance | 正常周期和会计噪声允许的范围 |
| weaken_trigger | 进入减弱状态的条件 |
| break_trigger | 逻辑被证伪的条件 |
| confirmation_window | 需要几个可比期间确认 |
| review_frequency | 月度、季度、半年或事件触发 |

断言应聚焦决定价值的少数变量，不把所有财务指标都设成触发器。

## 3. 触发器等级

### 硬红旗

通常无需等待第二个期间：

- 审计否定、无法表示意见，或可信证据指向重大财务造假；
- 控股股东非经营性资金占用、重大未披露关联交易或资产转移；
- 违约、持续经营重大不确定性、融资渠道关闭或短期偿债明显失配；
- 核心牌照、控制权、专利、关键客户或商业模式合法性丧失；
- 原投资逻辑依赖的核心事实被直接证伪。

硬红旗原则上将状态升级为“破坏”，同时降低证据置信度并启动立即风险复核。

### 核心触发器

直接对应投资断言，例如销量、提价能力、续费、同店、订单、单位经济、ROE中枢或归一化利润。单期大幅偏离可以先进入“减弱”；超过预设确认期限仍未恢复，或管理层解释与现金、渠道和外部证据矛盾时，升级为“破坏”。

### 软触发器

招聘、搜索热度、单店客流、媒体情绪和管理层措辞只能作为辅助证据。两个以上独立软信号方向一致并持续时，可以进入“减弱”，不能单独判为“破坏”。

## 4. 常见触发器类别

- **需求与护城河**：销量、客户留存、市场份额、价格折扣、渠道库存、替代品；
- **盈利能力**：毛利率、经营利润率、单位经济、ROE及其驱动因素；
- **现金与偿债**：经营现金转换、自由现金流、现金消耗、有息债务和到期结构；
- **资本配置**：分红、注销式回购、增发、并购回报和关联投资；
- **治理与披露**：审计意见、资金占用、管理层承诺兑现、口径频繁变化；
- **行业与周期**：供需、价格、库存、产能退出、政策和周期位置；
- **估值**：盈利或净资产更新后的PR、PE、PB、现金覆盖与情景价格。

不同行业选择不同的少数关键指标。金融企业还要使用资产质量、资本充足率、拨备和信用成本；周期股使用归一化盈利而非顶部利润；成长股必须检查增长质量、再投资回报和稀释。

## 5. 状态聚合规则

1. 任一可信硬红旗触发：基本面状态通常为“破坏”。
2. 一项核心断言被直接证伪：为“破坏”。
3. 一项核心触发器明显偏离但仍在确认期，或多个软触发器持续同向：为“减弱”。
4. 所有核心断言仍获支持且无硬红旗：为“成立”。
5. 关键指标缺失、口径不可比或报告明显过期：为“证据不足”，不得默认为成立。

不能用其他指标表现良好去平均掉已经触发的硬红旗。

## 6. 估值兑现退出

### 6.1 市场风险复核线与个股提前线

先定义市场风险复核线`E`：

```text
A股／美股及未另行校准市场：E = 1.00
港股／H股：E = 0.80
```

`E`是已持有资产必须立即复核的统一风险线，不是单指标清仓线。港股的`0.80`是用户确认的固定市场折价；观察到的公司PR不乘系数。对历史上常在 `PR<E` 见顶的个股，用其历轮高点市赚率建立更低的提前复核线；对长期合理PR高于`E`的优质企业，保留`E`警报但由公司自身历史和独立内在价值模型判断是否真的高估。

退出主口径必须与当前估值口径可比：

- 稳定价值股当前快照使用同截止日、同股份和同会计口径的`PE_TTM / ROE_TTM`；完整TTM存在时不得使用单季乘四；
- 当前TTM或最近三年任一ROE超过40%时，继承估值交接的`extreme_roe_review_required`和`roe_reliability`。确认长期回购压缩净资产、负净资产或杠杆导致ROE失真时，PR只作诊断，不得生成峰值统计或退出执行线；改用ROA／ROIC检验经营质量，并用正常资本结构重算ROE；
- 周期股使用同一完整周期规则下的归一化 `PR_PB`，不用景气顶部利润；
- 使用股东回报修正时，历史与当前必须同时使用基础口径或修正口径，不得混搭；
- 无法可靠计算市赚率时标为 `unpriceable`，启动证据修复或替代估值复核，不能因此默认尚未进入退出区。

### 6.2 历轮高点样本

1. 使用复权月收盘价，原则上覆盖近10年或上市以来可用全历史。稳定股至少需2轮，周期股必须尽量覆盖一个完整业务周期。
2. 候选峰值默认为：本轮月度收盘高点后12个月内出现至少20%最大回撤。高波动或周期股可把回撤门槛提高到30%，但必须在看到结果前固定公司全历史的同一规则。
3. 相距不足12个月的多个峰值合并为同一轮，取其中收盘价最高点，防止一次顶部震荡被重复计数。
4. 每个峰值只使用当日前已公开、当时可得的财务数据、股份数和会计口径重算PR，不得使用峰值后才披露的利润或事后修正数据。
5. 拆股、配股、大额回购、增发、准则切换或业务模型根本变化时先恢复可比性；无法恢复的轮次剔除并说明。
6. 负利润、负净资产或ROE口径失真导致PR无经济含义的轮次不纳入均值，但必须保留在剔除清单中，不得静默删除不利样本。

样本表至少展示峰值日期、峰值价格、当时可得盈利／净资产与ROE、计算路径、峰值PR、后12个月最大回撤和数据质量。计算：

```text
峰值平均PR = 各有效轮次峰值PR的等权算术平均
峰值中位PR = 各有效轮次峰值PR的中位数
低于市场风险复核线的峰值比例 = 峰值PR < E的有效轮次数 / 有效轮次总数
```

有效样本至少3轮时才可把统计锚标为中等或高置信；2轮只能低置信使用；0–1轮只作参考，不生成伪精确个股阈值。

### 6.3 个股锚、提前线与风险标记

个股历史峰值锚 `H` 默认为：

```text
H = min(峰值平均PR, 峰值中位PR)  # 防止极端泡沫轮抬高均值
普通提前退出线 S = 0.85 × H
高离散／高周期提前线 S = 0.80 × H
```

必须同时报告用户要求的“峰值平均PR”；取较低的平均值与中位数只是为了不让单次极端泡沫把退出线上移。高离散默认指峰值PR变异系数大于30%，或业务已被识别为强周期。

出现以下任一情况，标记 `pre_hard_exit_peak_risk: true`：

- 峰值平均PR或峰值中位PR低于 `E`；
- 至少一半有效轮次在 `PR<E` 后开始明显回撤；
- 可比的最近两轮均在 `PR<E` 见顶。

若有重大业务模型、资本结构或股东回报政策变化，历史锚只能降置信或停用，不得仅因“这次不一样”上移。`H`可以高于或低于`E`：高于时说明统一市场线应先触发复核而非自动退出；低于时说明公司历史可能要求更早检查。历史长期水平不是合理价值证明，仍须由最新同口径盈利和基本面状态校验。

### 6.4 默认分批退出阶梯

下列比例指相对设定退出计划时持有股数的**累计减仓比例**，而非每档再卖同样比例：

| 阶段 | 触发PR | 默认累计减仓 | 动作边界 |
|---|---:|---:|---|
| 提前兑现 | `S` | 10%–15% | 触发复核；公司历史、最新盈利和基本面确认后开始兑现，否则仅暂停估值性加仓 |
| 历史高点区 | `H` | 30%–40% | 公司历史与最新同口径盈利确认后减仓 |
| 市场风险线 | `E`（港股／H股`0.80`；其他基础`1.00`） | 不单独规定 | 进入`hard_exit_review`；不得只凭PR清仓 |
| 确认加速线 | `M=(H+E)/2`，仅当`H<E` | 50%–70% | `PR≥M`且历史、最新盈利和基本面共同确认高估后加快减仓；`H≥E`时本档不适用 |
| 硬退出 | 基本面破坏，或市场线、公司历史与最新盈利共同确认明显高估 | 80%–100% | 禁止估值性加仓；剩余仓位必须有明确理由和最迟处置日 |
| 确认高估后继续上涨 | 每增加 `0.10 PR` 或较上次卖出价再涨10% | 每次卖出剩余仓位的25%–50% | 执行“越涨越卖”，但每次用新价格刷新同口径估值 |

不得删除 `S`、`H` 和 `E` 三个关键信息，但三者都是复核触发器，只有经过公司历史、最新同口径盈利和基本面状态确认后的累计减仓比例才具有执行意义。用户有税务、流动性、持有期或最低核心仓要求时，可在不改变触发状态的前提下调整比例和时间；保留仓位不得被写成估值仍然便宜。

例如，对非港股，三轮可比峰值PR为 `0.72／0.81／0.76`：平均约 `0.76`、中位数 `0.76`，因此 `H=0.76`；普通提前线 `S≈0.65`，确认加速线 `M=0.88`。对港股／H股，同一组样本的`H=0.76`、`S≈0.65`，`M=(0.76+0.80)/2=0.78`，市场风险复核线为`0.80`。这些线先触发复核，减仓比例须等最新同口径盈利和基本面状态确认。

各档价格在其他输入不变时按同一口径映射：

```text
阈值价格 = 当前价格 × 目标PR / 当前PR
```

价格每跨过一档或比上次估值基准价变动默认8%时重算PR。若跨档由盈利、ROE、净资产、股东回报修正或股份数变化造成，旧的价格映射立即失效，须先重做估值与基本面复核。

### 6.5 执行纪律

- 估值退出使用计划时持有数为基数，同一档减去已执行数，避免把“累计比例”误当成每档比例。
- 价格跳过多档时，直接补到新档要求的累计减仓比例，不必逐档等待。
- `PR≥E` 后立即暂停估值性加仓并完成公司历史、最新同口径盈利和基本面复核，不得以新高为理由把风险线上移。只有完成可追溯的新基本面、新股东回报口径、同口径估值和新历史可比性审查后，才能建立新版计划；旧版必须保留。
- 分红、回购、停牌、日均成交额、滑点、税务和市场结算可以影响执行节奏，但不改变已触发的估值状态。
- 若基本面先进入“破坏”或出现可信硬红旗，优先按风险退出处理，不等待估值阶梯或更高卖价。

## 7. 压力情景

根据公司类型选择最小充分模型：

```text
稳定价值股：压力EPS × 压力PE，或在ROE可靠性已通过时使用压力ROE对应的PR价格；高ROE失真时改用FCF／EV类模型与正常资本结构ROE
周期股：压力净资产 × 压力PB，使用周期归一化ROE
成长股：下调收入、利润率和退出倍数后的区间
金融企业：压力净资产、信用成本、资本充足率与压力PB
```

至少分别输出“减弱”和“破坏”两个情景的：当前价格、压力价格下限和上限、压力损失比例、情景期限、主要假设和不可量化风险。若存在跳空、停牌、流动性或控制权风险，说明实际损失可能超过模型区间。

损失一律按同一基准计算：

```text
压力损失率 = (当前价格 - 压力价格) / 当前价格
```

若用户指定以持仓成本、组合净值或其他基准计算，另列结果并保留 `loss_basis`，不得覆盖按当前价格计算的可比口径。

## 8. 仓位交接判定

仓位交接必须保留三类不能互相替代的信息：

- **逻辑状态**：决定能否新增风险；“减弱”通常暂停加仓，“破坏”禁止加仓并启动退出评估；
- **安全边际强度**：在“安全边际仍在”内部继续区分强、中、薄，避免刚触及观察带也被当成深度低估；
- **情景损失**：分别给出逻辑减弱和逻辑破坏的损失，不让仓位公式自行猜测应使用哪个区间。

复查紧迫度使用 `normal / elevated / immediate`。已披露但未解决、尚未达到硬红旗的治理或经营事件可标为 `elevated`；可信硬红旗或需要在下一交易决策前处理的事件为 `immediate`。

估值退出对新增风险的交接是硬约束：`below_start` 仍按基本面与安全边际判断 `add_permission`；`early_exit`、`historical_peak_zone`、`approaching_hard_exit`和`hard_exit_review`至少为 `paused`；只有经公司历史、最新盈利与基本面共同确认的`hard_exit`或基本面破坏才为 `prohibited`。

## 9. 版本纪律

每次修改投资断言或阈值时保留：旧值、新值、修改日期、新证据、修改原因和批准者。触发后放宽阈值属于高风险变更，必须显著披露，不能覆盖原记录。
